# S2：PEG 解析器内核（日月 实现）计划

> 依据：docs/superpowers/specs/2026-09-29-peg-parser-design.md §8；本阶段启动时已确认两个开放问题（§11.2/§11.3）。

## 用户已确认的 S2 决策

- **语法树形态**：**类型化节点**（每个规则可带语义动作，构造具体 日月 结构体节点，而非通用 CST）。
- **语义动作**：**支持 `{ … }` 语义动作语法**（PEG.js 风格）。

### 由决策推导的两种模式职责（关键架构决定）

| 模式 | 输出 | 是否执行动作 |
|---|---|---|
| 解释模式（识别） | **通用 CST**（规则名 + 子节点 + 匹配文本）| **否**（仅产出结构树，用 `树.心` 打印）|
| 生成模式（生成代码） | 日月 递归下降解析器源码 | **是**（动作代码被原样嵌入生成的解析函数）|

理由：在 日月 里「解释执行语义动作」需要内建一个 日月 求值器/即时编译，成本过高；而动作的语义天然属于「生成代码」模式。解释模式产出通用 CST 已满足「识别语法、输出语法树」。

## 现状与先决差距（研究结论）

- 运行时已有动态数组：`源/运行时/运行时辅助.c:1367+`（`动态数组` int、`动态字符串数组`），宿主内置表 `源/共享/内置函数元数.h:31-35`、`源/共享/内置函数表.h:81-114`（`创建动态数组/动态数组添加/获取动态数组元素?/动态数组获取/动态数组设置/动态数组大小/求大小/动态数组删除/动态数组插入`）。
- **差距 P1**：自举编译器（自举/语法.心 解析括号或调用 的内置分发）**没有**这些动态数组内置 → 自举链无法编译用动态数组的 日月 程序（如 标准库/集合.心）。需补齐。
- **差距 P2**：结构体**自引用/前向引用**（如树节点 `子: 节点[N]`）会被 `结构体成员类型转IR` 判为未知 → i32。需在收集前**预登记所有结构体名**。
- **差距 P3**：结构体成员数组的元素类型为**结构体**时，元素码应映射为 `ptr`（当前只支持 I/S/F）。
- **差距 P4（可选）**：映射**下标写**（记忆化缓存）与**局部带类型数组声明**。首版可绕过（无记忆化、用动态数组或字面量）。

## 文法文件格式（新设计，含动作）

```
# 行注释以 # 或 // 开头；空行忽略
%token  整数    [0-9]+
%token  标识符  [A-Za-z_\u4e00-\u9fff][A-Za-z0-9_\u4e00-\u9fff]*
%keyword 如果
%skip   空白    [ \t\r\n]+
%skip   注释    //[^\n]*

程序     = 声明* 结束
声明     = 函数定义 / 变量声明
函数定义 = '函数' 标识符 '(' 参数列表? ')' 代码块 { 结果 = 建函数(节点1, 节点2); }
```

PEG 表达式文法（优先级从低到高）：

```
有序选择 = 序列 ( '/' 序列 )*            # 最外层
序列     = 项+  [ 动作 ]                 # 项以空白分隔；可选尾随动作
项       = ('&' | '!')? 后缀
后缀     = 主表达式 ('*' | '+' | '?')?
主表达式 = 单引号字面量 | 双引号字面量 | 规则名 | '.' | '(' 有序选择 ')' | 标签 ':' 项
标签     = 标识符
动作     = '{' <日月代码原文> '}'
```

约定：
- `'字面量'`/`"字面量"` 匹配**单个 token 的文本**（等价于 token 终结符）。
- 规则名引用另一条规则；`.` 匹配任意一个 token（不推进则不匹配）；`&`/`!` 前瞻不消费。
- `标签:项` 把该子结果绑定到动作里的变量 `标签`；序列中未命名的项绑定 `节点1..节点N`。
- 动作内把结果写入**预声明变量 `结果`**（规则返回它）。无动作的规则默认返回通用 CST 节点。
- `%keyword 词` 是「保留字的 token 类型」；`%token`/`%keyword`/`%skip` 用正则子集（字面量、`[]` 字符类、`* + ?`、`|`、`()`、转义）匹配。

## 工具结构（工具/peg/，日月 实现，用 导入 拆多文件）

| 文件 | 职责 |
|---|---|
| `工具/peg/词法.心` | 正则子集匹配器（`正则匹配(模式, 输入, 起始) -> 结束位置`），以及将输入切成 token 流 |
| `工具/peg/文法.心` | 读文法文件 → 规则表（token 规则 / skip 规则 / 关键字 / PEG 规则 AST）|
| `工具/peg/匹配.心` | PEG 引擎：在 token 流上做有序选择 / 序列 / 重复 / 前瞻；回溯（保存/恢复 token 游标）；产出通用 CST |
| `工具/peg/树.心` | 通用 CST 节点（`结构体 节点{ 类型: 字符串; 文本: 字符串; 子: 节点[N]; 子数: 整数; }`）+ 打印 |
| `工具/peg/生成.心` | 生成 日月 递归下降解析代码（含类型化节点 + 语义动作嵌入）|
| `工具/peg/主程序.心` | CLI：`识别 文法 输入` / `生成 文法 输出.心` |

## 任务切分

- **S2.0 先决编译器增强**（每个都要求 `make 自举` 不动点 + `test_all23` 不回归）：
  - S2.0.1 自举内置函数补齐动态数组/动态字符串数组（P1）：发射前导加声明；解析括号或调用 内置分发加分支；内置函数元数（自举侧若有表）对齐。
  - S2.0.2 结构体名预登记（P2）：第二遍/收集前先扫一遍所有 `结构体 名` 登记名字（占位大小），使成员类型解析对任意（含自引用/前向）结构体名 → `ptr`。
  - S2.0.3 结构体成员数组元素类型为结构体（P3）：`收集结构体定义` 中元素码增加 `O`→ptr；`数组元素转IR` 增加 `O→ptr`；`数组对齐` 保持 8。
- **S2.1** `词法.心` 正则子集匹配器 + token 化；玩具词法单测。
- **S2.2** `文法.心` 读文法文件 → 规则表（含 PEG 规则 AST）。
- **S2.3** `匹配.心` + `树.心`：解释模式在玩具文法（算术表达式 + 括号 + 变量）上产出并打印 CST。
- **S2.4** `生成.心`：对玩具文法生成 日月 解析器源码，编译运行，验证与解释模式同一输入结果一致。
- **S2.5** 收尾：`主程序.心` CLI 两种模式；示例/测试；文档。
