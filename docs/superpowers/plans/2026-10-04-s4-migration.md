# S4 迁移 计划（路线2 完全自举 + 日月文法语义动作）

> 目标：把前端彻底迁到「生成解析器 + 真语法树」之上，并让 **日月.exe 由自举链产出**（宿主 C++ 编译器仅作引导种子）。
> 上位文档：docs/superpowers/specs/2026-09-29-peg-parser-design.md §10 / §11。

## 用户决策（本阶段启动确认）

1. **宿主前端路线 = 路线2 完全自举**：宿主不再需要自己的前端；`日月.exe` 改由自举编译器产出，重排构建链。C++ 编译器降级为**引导种子**（`引导.exe`）。
2. **语法树构造方式 = 日月.文法 语义动作**：给 `工具/日月/日月.文法` 增加 `{…}` 动作，由 日月 结构/容器直接构造真树对象（S3.2 生成模式动作已支持）。
3. S3.5（解释模式内建求值动作）**延后**；路线2 不需要它（`日月.exe` 即自举编译器，C++ 侧不解析 日月 源码）。

## 现状（S1–S3 产物，均已提交并推送）

- 自举编译器 = 4 文件文本包含：`自举/编译器.心`(全局+导入+主程序) + `自举/词法.心`(下一个标记 等) + `自举/发射.心`(IR 发射助手/类型表) + `自举/语法.心`(手写递归下降 + **边解析边发射**)。
- 结构：**两遍扫描 token 流**——`第一遍`(语法.心:1880) 收集全局/函数原型/结构体/枚举；`第二遍`(语法.心:1930) 再扫一遍**边解析边发射** IR。表达式结果经全局 `表达式C/表达式类型` 传递（如 `解析或` 语法.心:85）。**无语法树**。
- PEG 工具（`工具/peg/`）：`词法.心`(正则子集)、`文法.心`(%token/%skip + 规则表)、`匹配.心`(解释模式；**CST 是文本字符串** `匹节点:字符串`)、`生成.心`(生成 日月 递归下降源码；生成代码全局 `解析结果/解析成功/解析位置`，输出**文本 CST**)、`主程序.心`(CLI 识别/生成)。
- `工具/日月/日月.文法`(134 行)：日月 全语言词法+文法，**纯结构、无动作**；`peg_cli 识别` 与生成解析器对全部 `示例/*.心` 逐例一致 84/84；host/boot 生成源码逐字节一致。
- 后端 alloca 提升修复 `8b57200`；生成模式 收集段修复 `977d2a4`。

## 关键约束与风险

- **日月 无继承/无和类型**（结构体继承延后 D10）→ C++ 侧 `表达式`/`语句` 的多态树**不能照搬**。真树须用 日月 可表达的形式：**扁平节点池**（每节点：种类码 + 名/文本 + 子索引列表），以动态数组或换行表维护，索引即节点句柄。此为 S4-A.0 的定型任务。
- **引导顺序**：生成的解析器源码（含 AST 动作）必须是 自举编译器**能编译**的 日月 代码，且在 `编译器.心` 里用 `导入` 文本包含展开；因此构建必须先产出解析器源码，再编译编译器。
- **不动点**：任何 自举/*.心 改动后 `make 自举` 必须仍收敛；`test_all23.ps1` 不得回归（既有 2 例 数学工具/数学模块 属预存在缺陷）。
- **AST 保真**：生成的 AST 必须能驱动现发射层产出与旧手写前端**语义等价**的 IR（用 不动点 + 示例 host/IR 输出一致 验收）。

## 任务切分

- **S4.0 定型 AST 表示**（spike）：用 日月 容器实现扁平节点池（`节点种类`/`节点名`/`节点文本`/`节点子索引` 等并行结构 + 分配器）。产出 `自举/语法树.心`（含 节点构造原语 `新节点(种类)/加子(父,子)/设文本(...)` 与 种类码常量）。小样例 手工构树 + 打印 验证。
- **S4.1 生成器库模式**：扩展 `工具/peg/生成.心`，除 CLI 外生成一个**库入口** `解析(源码) → 根节点索引`（不再依赖运行时解析文法；或内嵌规则表）。生成源码放 `工具/peg/生成_日月.心`，作为 编译器.心 的导入。
- **S4.2 日月.文法 增加语义动作**：按 `源/前端/抽象语法树.h` 的节点，分步给规则加 `{…}` 动作构造 AST——先**表达式链**（算术/比较/逻辑/原子/后缀），再**语句**，再**顶层/函数/结构体/枚举**。每步用小型样例对比「解释 CST 结构」与「动作建树」。
- **S4.3 编译器接入**：`编译器.心` 的解析阶段改为「读源码 → 生成解析器 → AST 根」；`第一遍/第二遍` 改为**遍历 AST**（先收集原型，再发射）。
- **S4.4 发射层改造**：`发射表达式语句`/`发射函数定义`/`解析并发射语句` 等改为**消费 AST 节点**（函数名改为 `发射表达式(节点)`/`发射语句(节点)`），复用既有 IR 发射助手（`发射.心` 尽量不动）。
- **S4.5 验证**：`make 自举` 不动点；`test_all23.ps1` 不回归；抽样 `示例/*.心` 在「宿主链 vs IR 链」输出一致。
- **S4.6 构建链重排（路线2）**：Makefile 中 C++ 版改名为 `引导.exe`；新增目标使 `日月.exe`（自举产物）经 `引导.exe → 一级.exe → … → 自举 日月.exe` 产出；`test_all23.ps1`/`运行` 默认用自举 `日月.exe`。

## S4.2 进展与 AST 动作约定（2026-10-04）

已完成：
- S4.2a `b7de257`：生成器默认归约改为**节点池真树**；`树转CST` 逐字节复现原 CST（84/84 保持）。
- S4.2b `dee12f9`：**动作模式**开关。CST 模式（默认）忽略 `{…}`（与解释器一致）；`生成树`（动作模式=1）执行动作建 AST。

节点池 API（`自举/语法树.心`）：`(种类,文本,子列表)新节点->整数`、`(种类,文本)新叶->整数`、`(节点)取种类/取文本/取子数`、`(节点,序号)取子`、`()新子列表->字符串`、`(列表,子)子列表添加`、`(节点)树转CST->字符串`。句柄 `-1` = 缺失。

动作环境：动作体注入为 `如果 (解析成功 ?= 1) { 0 = 结果; <动作> 结果 = 解析结果; }`（在 `生成序列` 末尾）。此时 `解析结果` = 该序列的**默认归约节点**（多子=匿名容器 `("","",子)`；单子=叶/子节点）。动作可读取该结构并用上列 API 构造新节点赋给 `结果`。**动作必须单行**（文法按行解析，`;` 分隔）。

规则级约定：规则**若有动作，其每个备选段都必须带动作**（否则该段结果为默认容器）；带动作规则的默认包裹被抑制，`解析结果` 直接取动作的 `结果`。

AST 节点种类/字段约定（对齐 `源/前端/抽象语法树.h`，`种类` 串用枚举名）：
- 叶：`整数`/`浮点数`/`字符串`/`字符` → 文本=字面量原文；`布尔值` → 文本=`真`/`假`；`变量` → 文本=名。
- `二元运算` → `("二元运算", 运算符, [左,右])`；`一元运算` → `("一元运算", 运算符, [操作数])`。
- `函数调用` → `("函数调用", 被调名, [参数…])`；`下标访问` → `("下标访问","",[对象,下标])`；`成员访问` → `("成员访问", 成员名, [对象])`。
- 字面量：`数组字面量`/`元组字面量`/`映射字面量` → `("…","",[元素…])`。
- `条件表达式` → `("条件表达式","",[条件,真,假])`；`空值合并` → `("空值合并","",[左,右])`。
- 语句：`表达式语句` → `("表达式语句","",[表达式])`；`赋值语句` → `("赋值语句","",[值,目标])`；`代码块` → `("代码块","",[语句…])`；如果/当/循环/返回/遍历/匹配… 按语法子节点顺序。
- 顶层：`导入语句` → `("导入语句", 路径)`；`函数定义` → `("函数定义", 名, [参数…,返回值…,主体])`；结构体/枚举/类型别名/全局声明 类似。

左结合折叠：`或 = 与 (或或 与)*` 等默认归约容器子 = `[首项, 量词容器]`，量词容器子 = 各 `op 项` 对（每对=匿名容器 `[op叶, 项]`）。动作须将扁平结构左折叠为 `二元运算`；建议给组内 `(或或 与)` 段内联动作直接建 `二元运算` 节点，使外层只需按序右折。

## S4.4 详细实施计划（发射层改造：走 AST）

### 目标与验收
- `编译器.心` 主程序改为：读源码 → 处理导入（文本合并）→ `()库初始化` → `(合并源码)解析根` → `发射程序(根)`。
- 不再使用 `自举/词法.心`（分词）与 `自举/语法.心` 的 token 递归下降；发射辅助 `自举/发射.心` 尽量不动。
- 验收（S4.5）：`make 自举` 不动点；`test_all23.ps1` 不回归（允许 2 个预存在的 数学工具/数学模块 失败）；抽样 `示例/*.心` 宿主链 vs IR 链产出一致。

### 模块布局（决策）
- 新增 `自举/语法_树.心`：AST → IR 发射器。函数：`发射表达式(节点)->设 表达式C/表达式类型`、`发射语句(节点)`、`发射函数节点(节点)`、`发射程序(根)`、`发射闭包(节点)`。
- `自举/编译器.心`：把 `导入 "语法.心"` 改为 `导入 "语法_树.心"`，并 `导入 "自举/解析器.心"`（其再导入 `工具/peg/匹配.心`）。`导入 "词法.心"` 保留与否待定（旧符号不冲突，但迁移完成后应删）。
- 保留 `自举/语法.心` 与 `自举/词法.心` 作过渡期备份（固定点验证通过后再删）。

### AST 实际种类串（以 `自举/解析器.心` 为准）
- 顶层：`程序`/`函数`/`协程`/`结构体`/`枚举`/`导入`/`全局变量`/`类型别名`。
- 函数：`(函数 [参数表?] [标识符 名] [返回表?] [代码块])`；参数 `输入形参`/`输出形参`（`(输出形参 (标识符 名) (类型 整数)? )` 形如 `(标识符 名)(类型 T)`）。
- 语句：`代码块`/`返回`/`如果`/`如果头`/`当`/`做`/`循环`/`循环头`/`循环C`/`遍历`/`匹配`/`分支`/`尝试`/`中断`/`继续`/`抛出`/`让出`/`赋值`/`表达式语句`/`结构体`/`枚举`（块内定义）。
- 表达式：`整数`/`浮点数`/`字符串`/`插值字符串`/`字符`/`布尔值`/`变量`/`二元运算`/`一元运算`/`条件表达式`/`函数调用`/`元组`/`后缀`（链）/`成员访问`/`元组访问`/`双冒访问`/`成员调用`/`下标访问`/`分片`/`结构体实例`/`实例成员`/`管道`/`管道映射`/`额外参数`/`映射字面`/`推导字面`/`数组字面`/`匿名函数`/`参数列表`(匿名容器)。

### 子阶段（每步须 `make 自举` 不动点 + 回归）
- **S4.4a 表达式发射**：`发射表达式(节点)`，逐种类复用 `自举/语法.心` 现有 IR 序列（类型推导/字符串拼接/浮点提升/比较/函数调用/内建分派/下标/成员/映射/元组/数组/后缀）。验证：独立样例文件 AST 发射的 IR 行为与原路径一致。
- **S4.4b 语句发射**：`发射语句(节点)`：表达式语句/赋值/复合赋值/如果/当/循环/遍历/匹配/返回/中断/继续/代码块。
- **S4.4c 顶层与两遍**：`发射程序(根)`：第一遍收集 函数原型/结构体/枚举/全局（走 AST），第二遍发射结构体类型 + 函数体 + 闭包。
- **S4.4d 闭包**：AST 版捕获分析（`匿名函数` 节点 → 内部函数 + 捕获 ptr 形参）。
- **S4.4e 接入与固定点**：改 `编译器.心` 主程序；`make 自举` 收敛；`test_all23` 回归。

### 关键风险与对策
- **AST 保真**：`如果语句`/`匹配` 的重复组经 `收集` 扁平化后须能按位置还原配对（`如果头 代码块 (表达式 代码块)* 代码块?`）；不足处需先补/改 日月.文法 动作。
- **寄存器命名**：AST 遍历顺序须与原 token 顺序一致，否则 IR 文本不同（可不追求逐字节，但须行为一致）。
- **两遍结构**：结构体自引用占位、函数前向引用、全局发射顺序须保持。
- **类型信息**：AST 叶只带文本；变量类型来自 `局部类型表`/`全局表`/`结构体_*` 登记，须在发射期正确维护。
