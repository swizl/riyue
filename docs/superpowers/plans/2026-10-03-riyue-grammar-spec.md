# 日月 文法规格（S3.4 参考，摘自 源/前端/语法分析器.cpp + 抽象语法树.h）

Note: `=` 是赋值（值在左）；`?=` 是相等；移位是 `<|`/`>|`（**无 `<<`/`>>`**）。

## 顶层
程序 = 顶层声明*
- 字面量开头(整数|浮点|字符串|真|假) → `值 [=变量] 名 [:类型] ;` 全局变量声明
- `结构体 名 [: 基类] { … }`
- `导入 "路径" ;`
- `枚举 名 { 成员 [=整数] , … }`
- `整数|浮点|布尔|字符串|标识符` 开头 → 试探 `原始类型 = 别名 :类型 ;`（类型别名）；否则回退 函数
- `协程` → 协程函数；其它 → 函数

## 函数
函数 = `函数` [ `<`类型参数[:约束](,…) `>` ] [ `(`输入参数表`)` ] 函数名 [ 返回值表 ] 代码块
短式：`函数 主程序 { 语句* }`
- 输入参数表(在函数名之前) = 形参 `[字面量 =] 名 [:类型] [=表达式] [...]`
- 返回值表(在函数名之后) = `(空)` | `(输出参数 …)` | ε

## 语句
- `值 = (v1,v2,…) ;` 解构赋值
- `值 = 常量 名 ;` 常量声明
- `值 = 名.成员 ;` 赋值 · `值 = 名[索引] ;` 下标赋值
- `值 = 名 [:类型] ;` 变量声明 · `值 抛出 ;` · `值 让出 ;` · 表达式语句
- 标识符开头回退：`名[索引]=值;` · `名.成员=值;` · `名=值;` · `名 op= 值;`(op∈+= -= *= /= %= &= |= ^= <|= >|=) · `名+| ;`/`名-| ;`
- `如果 (…条件…) 块 (否则如果 (…) 块)* [否则 块]`（含 `如果 (值=变量名[:类型]; 条件)`）
- `循环 (名:开始,结束[,步长]) 块` | `循环 ([init];[cond];[step]) 块` | `循环 块` | `当 (条件) 块` | `做 块 当 (条件);` / `做 块 到 (条件);`
- `中断 ;` `继续 ;` `返回 [表达式] ;`
- `匹配 (表达式) { 分支* }` 分支 = (`表达式`|`_`) `=>` `{ 语句* }`
- `遍历 (名:数组表达式) 块`
- `尝试 块 [捕获 (名) 块] [最终 块]`
- `抛出 表达式 ;` `让出 表达式 ;`
- `结构体 名 { 成员(名:类型;) | 方法 名(参数)返回值表 块 }`
- `{ 语句* }`

## 表达式优先级（低→高，左结合）
1 条件 `c ? t : e`
2 空值合并 `??`
3 `||`
4 `&&`
5 管道 `左 | [(映射键=值,…)] 函数名 [(额外参数)]`（右侧须标识符，否则回退 位或）
6 `^`
7 `&`
8 比较 `?=` `!=` `<` `>` `<=` `>=`
9 移位 `<|` `>|`
10 加减 `+ -`
11 乘除 `* / %`
12 一元 `!` 前缀、一元 `-` 前缀（右递归）
13 原子/后缀

## 原子/后缀
- `整数`→整数表达式 · `浮点`→浮点表达式 · `真|假`→布尔表达式 · `字符`→字符表达式 · `字符串`→字符串表达式
- `"…{expr}…"` 插值 → 二元运算(加法) 链（字符串表达式 + 函数调用("转字符串")）
- `( 参数,… ) 函数名` → 函数调用表达式
- 标识符 + 后缀：`[索引]` 下标 · `[开始:结束]`/`[:结束]` 分片 · `.标识符` 成员 · `.整数` 元组访问 · `.方法(参数,…)` 方法调用 · `::成员` 枚举成员 · `{成员:值,…}` 结构体实例 · `+|`/`-|` 自增自减 · 裸 变量
- `[字符串:值,…]` 映射 · `[表达式 $ 变量 : 开始 , 结束 [,步长] [,过滤]]` 数组推导 · 否则 `[e,…]` 数组字面量（首元素在 位异或 层解析）
- `函数 (参数)返回值表 [:返回类型] 块` 匿名函数 · `入 (参数) : (表达式)` lambda
- `( e , e , … )` 元组 · `( e )` 分组

注：`空` = null/void 类型关键字；`入`/`类型`/`方法`/`字符串`/`结构体` 为保留字。`打印` token 存在但无产生式。
