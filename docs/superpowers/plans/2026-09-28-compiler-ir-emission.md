# compiler.心 发射层改为中文 LLVM IR 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `自举/compiler.心` 的发射层从 C 文本改写为中文 LLVM IR 文本，使自举管线变为 日月源码→IR→llvm-as→llc→ld.lld，彻底摆脱 C。

**Architecture:** 保持词法/类型表/两遍扫描/语句解析结构不变；表达式解析链从「拼接 C 表达式字符串」改为「发射三地址码指令并返回寄存器名」；前导、全局、函数定义、控制流全部改发射中文 LLVM IR。字符串字面量集中编号为 `@N` 常量；标识符统一裸写中文（已给 `llvm-as` 打补丁支持 UTF-8 标识符，见 Global Constraints）。

**Tech Stack:** 日月语言（自举/compiler.心，1176 行）；自定义中文 LLVM 23（llvm-as/llc）；MSYS2 的 ld.lld + mingw64 运行时 + crt2.o。

## Global Constraints

- 所有新全局状态用 `0 = 变量 名;`（整数）或 `"" = 变量 名;`（字符串）声明，位于文件顶部全局声明区。
- 标识符一律裸写（中文或 ASCII 皆可）：`@计数`、`%结果`、`@printf`、`%tmp1`、`@main`、`L1`。依据：llvm-project commit `4d734246b` 已让 `LLLexer.cpp` 的 `ReadVarName` 接受 `>=0x80` 字节，`@中文`/`%中文` 合法；转义形式 `@"\E4\B8\BB"` 仍向后兼容但不再使用。字符串**数据**（`c"..."` 常量内容）仍走字节转义（Task 2 Step 2）。
- IR 类型映射：整数→`i32`、字符串→`ptr`、浮点→`double`；对齐 `i32`=4、`ptr`=8、`double`=8、`i8`=1。
- 整数运算 opcode：`+`→`加`、`-`→`减`、`*`→`乘`、`/`→`有符号除`、`%`→`有符号取余`；比较谓词：`>`→`sgt`、`<`→`slt`、`>=`→`sge`、`<=`→`sle`、`==`/`?=`→`eq`、`!=`→`ne`；字符串比较经 `strcmp`；条件统一 `整数比较 ne i32 <expr>, 0`。
- 每函数临时寄存器用全局计数器产生 `%tmpN`（只增不重置，全模块唯一）；标签用 `L1`,`L2`,…（全局计数器）。
- 字符串常量：`@N = 私有 未命名地址 常量 [X x i8] c"...\00", align 1`，X=字节数+1，`\00` 必须加在引号内末尾。
- IR 指令/关键字用中文（加/减/乘/有符号除/有符号取余/整数比较/零扩展/加载/存储/分配/调用/返回/分支/标签/获取元素指针/定义/内部/声明/私有/未命名地址/常量/全局）。
- 三个 static helper 用裸中文名：`@辅助子串`、`@辅助拼接`、`@辅助转字符串`。名字经 `转义标识符`（现为原样直通）拼出、前缀写 `@`，即 `"@" + ("辅助子串")转义标识符` → `@辅助子串`；定义处与所有调用点均须如此。
- 运行时函数（设置参数/获取参数数量/获取参数/读取文件/写入文件/字符位置到字节位置/获取字符数/字符码/输出错误/分割行数/获取行/字符串开头）名字经 `转义标识符`（原样直通）存入全局，前导与内置分发时前缀 `@`，如 `"@" + 转义_设置参数` → `@设置参数`。
- 词法/类型表/第一遍结构/第二遍结构/主程序骨架保持不变；输出路径用 ASCII（stage/）。
- 编译与验证环境：MSYS2 bash；llvm-as/llc/ld.lld 运行时需 PATH 含 `/c/tools/msys64/mingw64/bin`。
