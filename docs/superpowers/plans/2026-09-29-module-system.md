# 模块系统（A1）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 日月 编译器（宿主 `源/` 与自举 `自举/编译器.心`）实现一致的 `导入` 模块系统，并把 `自举/编译器.心` 按职责拆成多文件。

**Architecture:** 宿主侧把导入信息放进 `程序` AST，新增递归 `模块合并器`（in-progress/已导入双集合、规范路径去重、同名冲突报错、导入者目录优先解析），入口改为按名字查找 `主程序`。自举侧 `编译器.心` 用「文本包含」实现 `导入`：读入源码后逐行扫描整行 `导入 "路径";`，解析路径、去重、环检测、递归读入并以处理后的模块文本替换该行，再交给既有两遍扫描。运行时 `UTF8打开文件` 增加本地代码页（CP_ACP）回退，使 stage1 能读中文路径（split 后模块文件是中文名）。最后把 `编译器.心` 的函数按 词法/语法/发射 三个模块拆出。

**Tech Stack:** C++17（LLVM 23 build 的 clang++/clang）、日月 语言（LLVM IR 后端）、MSYS2 bash、LLVM 23 中文方言、ld.lld、PowerShell 测试脚本。

- [ ] **Step 2: 改 `源/运行时/运行时辅助.c:16-35` 为双代码页回退**

把整个 `UTF8打开文件` 函数替换为：

```c
// 用路径打开文件（Windows 下转换为宽字符路径）。
// Windows 传给 main 的 argv 是本地代码页(CP_ACP, 如 GBK)字节，而源码/字符串常量里
// 通常是 UTF-8 字节，故先按 UTF-8 转换打开，失败再按本地代码页重试。
static FILE* UTF8打开文件(const char* 路径, const char* 模式) {
#ifdef _WIN32
    wchar_t 宽路径[1024];
    wchar_t 宽模式[64];
    UINT 代码页表[2] = { CP_UTF8, CP_ACP };
    int 索引;
    if (MultiByteToWideChar(CP_UTF8, 0, 模式, -1, 宽模式, 64) <= 0) return NULL;
    for (索引 = 0; 索引 < 2; 索引++) {
        if (MultiByteToWideChar(代码页表[索引], 0, 路径, -1, 宽路径, 1024) > 0) {
            FILE* fp = _wfopen(宽路径, 宽模式);
            if (fp) return fp;
        }
    }
    return NULL;
#else
    return fopen(路径, 模式);
#endif
}
```

```cpp

#include "语法分析器.h"
#include <fstream>
#include <algorithm>

静态 文本 统一分隔符(文本 路径) {
    循环 (自动& 每个字符 : 路径) {
        如果 (每个字符 == '/') 每个字符 = '\\';
    }
    归返 路径;
}

文本 模块合并器::目录部分(恒常 文本& 路径) 恒常 {
    大小类型 分隔 = 路径.find_last_of("/\\");
    如果 (分隔 == 文本::npos) 归返 "";
    归返 路径.substr(0, 分隔 + 1);
}

真假型 模块合并器::文件可读(恒常 文本& 路径) 恒常 {
    标准输入文件流 流(路径);
    归返 流.good();
}

文本 模块合并器::规范化绝对(恒常 文本& 路径) 恒常 {
    字符型 缓冲[MAX_PATH * 2] = {0};
    如果 (GetFullPathNameA(路径.c_str(), sizeof(缓冲), 缓冲, 空针) == 0) {
        归返 统一分隔符(路径);
    }
```
