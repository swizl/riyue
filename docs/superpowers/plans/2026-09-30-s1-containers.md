# 容器能力（S1）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让自举 `编译器.心`（拆分为 词法.心/发射.心/语法.心 四模块）支持 数组 / 结构体 / 映射 / `匹配` / `遍历` / 元组 / 枚举，语义对齐宿主，并按用户裁定修复 7 条宿主怪癖。

**Architecture:** 宿主（`源/后端/`）的容器语义已调研完毕（见 spec §7.1 与调研记录）。自举侧按宿主 IR 形态逐条复刻：
- 词法新增 token `[` `]` `.` `::` `=>`；
- 类型表新增类型码 `A`(数组) `M`(映射) `T`(元组) `E`(枚举) `O:<名>`(具名结构体)；
- 表达式层：数组字面量、映射字面量、元组字面量、结构体实例、下标读、成员读（链式）、元组访问、枚举成员；
- 语句层：下标写、成员写、`结构体` 定义、`枚举` 定义、`匹配`、`遍历`；
- 发射层：数组=`alloca [N x i32]`/`[N x i8*]`；结构体=具名 struct + `ptr`；映射=全局 `{ [N x i8*], [N x i8*] }` + `映射设置`/`映射获取`（容量 1024）；匹配=顺序 `icmp`/`strcmp`；遍历=索引循环；元组=具名 struct + 栈 alloca；枚举=编译期 i32 常量。

**Tech Stack:** 日月 语言（LLVM IR 后端，中文方言）、LLVM 23 补丁版 llvm-as/llc、MSYS2 bash、ld.lld、PowerShell 测试脚本。

### Task S1.1: 词法 + 类型表 + 数组

**Files:**
- Modify: `自举/词法.心`（token 识别）、`自举/发射.心`（类型码 A、数组 IR）、`自举/语法.心`（数组字面量、下标读写）、`自举/编译器.心`（新全局）
- Test: `示例/容器数组.心`（数组字面量、下标读写、`长度(数组)`、遍历）

**Interfaces:**
- Produces: token 值 `[`=… `]`=… `.`=… `::`=… `=>`=…（取不与现有 4=运算符 冲突的值）；类型码 `A`；发射 `全部oca [N x i32]`/`[N x i8*]`；`长度` 对数组分支返回 `N`。

- [ ] **Step 1: 词法.心 新增 token**
  在 `下一个标记` 的运算符分支加：`[` `]` `:`（单冒号已支持）`.` `:` 后跟 `:` → `::`；`=` 后跟 `>` → `=>`（现 `=` 分支遇非 `=`/`>`/`+`/`-`/`*`/`//` 的第三码时已回退单 `=`，需确认 `=>` 不被误回退）。token 值与 现有 0-5 类型不冲突。

- [ ] **Step 2: 发射.心 类型码 A 与数组 IR**
  类型码 `A`：数组变量。`类型转IR` 加数组 → 保持 i32* 语义（数组=指针）；`取地址` 支持数组变量；`发射表达式语句` 的下标写：`目标[索引] = 值` → 按数组元素类型 GEP+store；下标读 → GEP+load。数组字面量（表达式上下文）：按元素类型推断 `[N x i32]`（全整数/浮点）或 `[N x i8*]`（含字符串），混合类型报「错误: 数组字面量混合类型」；浮点元素按 double 存进 `[N x double]`（宿主是 i32，本计划按裁定改）。

- [ ] **Step 3: 语法.心 数组字面量与下标**
  解析原子：`[` 后收集元素列表（逗号分隔）→ 数组字面量表达式；元素类型推断 + 混合报错。下标：主表达式后跟 `[` 索引 `]` → 下标表达式（读）；赋值目标含下标 → 下标写。

- [ ] **Step 4: 长度() 数组分支 + 遍历 尺寸判定（怪癖 1/6）**
  内置分发 `长度`：实参是数组变量 → 直接返回数组大小（编译期 N）；字符串 → 运行时 `获取字符数`。`遍历(变量:对象)`：对象是简单变量且数组类型 → 用数组大小；否则**报错**「错误: 遍历对象无法确定长度」（怪癖 1，不再写死 100）。

- [ ] **Step 5: 验证**
  - 新建 `示例/容器数组.心`：定义数组、下标读写、`长度(数组)`、`遍历`；打印结果。
  - `日月.exe 示例/容器数组.心 C:/…/host.exe` 运行得输出 A；`一级.exe 示例/容器数组.心 C:/…/boot.exe` 运行输出 B；**A==B**。
  - `make 自举` 不动点；`test_all23.ps1` 79/0（新增示例成为第 80 个文件时改为 80/0，下面各步一致递增）。

### Task S1.2: 结构体 + 链式成员

**Files:**
- Modify: `自举/词法.心`、`自举/发射.心`（类型码 O、结构体 IR）、`自举/语法.心`（结构体定义、实例、链式成员读写）、`自举/编译器.心`（结构体元数据表）

**Interfaces:**
- Produces: 类型码 `O:<名>`；结构体定义收集（名称→成员名列表+成员类型列表）；实例 `名{成员: 值,…}`；链式成员读/写 `a.b.c` 与 `a.子[0]`（怪癖 4）。

- [ ] **Step 1: 结构体定义解析 + 元数据表**
  语句层 `结构体 名 { 成员: 类型; … }`：把成员名/类型存全局表（编译器.心 声明新表 `结构体_成员表`/`结构体_成员类型表`，键=`结构体名:成员名` 或列表）。类型名 `名`（在结构体表）→ 类型码 `O:<名>`。

- [ ] **Step 2: 结构体实例 + IR**
  实例 `名{ 成员: 值 }` → 按定义成员顺序 alloca 具名 struct、GEP+store。`类型转IR` O → ptr。

- [ ] **Step 3: 链式成员访问（怪癖 4）**
  解析：标识符后 `.` 递归成员链（`a.b.c`）；成员后允许 `[`（`a.子[0]`）。读：沿链逐级 GEP；写：末级 GEP+store。成员名查 结构体_成员表 得索引；链式中间节点若为结构体指针逐级查表。

- [ ] **Step 4: 验证**

### Task S1.3: 映射 + 遍历

**Files:**
- Modify: `自举/发射.心`（类型码 M、映射全局 IR）、`自举/语法.心`（映射字面量、下标读写映射分支、遍历）、`自举/编译器.心`（映射全局表）、`源/运行时/运行时辅助.c`（容量 256→1024；值支持整数——见 Step 2 裁定）

**Interfaces:**
- Produces: 类型码 `M`；映射=全局 `{ [1024 x i8*] 键, [1024 x i8*] 值 }` + `映射设置`/`映射获取`（运行时辅助.c 与 发射前导 的声明同步改 1024）；值支持 整数（转字符串存）/字符串（怪癖 3）。

- [ ] **Step 1: 映射字面量与全局发射**
  `["键": 值, …]` 前瞻首元素字符串+冒号 → 映射。全局变量发射 `{[1024 x i8*],[1024 x i8*]}`（发射前导声明 `映射设置`/`映射获取` 改 size 1024）。下标读走 `映射获取`，下标写走 `映射设置`。

- [ ] **Step 2: 值类型支持整数（怪癖 3）**
  映射值：字符串直接传；整数先调运行时 `辅助转字符串`（自举已有该 helper）得 i8* 再存。读回时统一当字符串用。

- [ ] **Step 3: 遍历（怪癖 1 落实）**
  `遍历(变量:对象){…}`：对象=数组 → 索引 for 循环（复用 S1.1 的尺寸判定）；对象=映射 → 遍历键数组（循环 0..容量-1，`映射查找` 跳过 -1）或仅支持数组（首版报错「遍历映射暂不支持」——按裁定 1 语义，映射无法确定「实际长度」）。

- [ ] **Step 4: 验证**
  - 新建 `示例/容器映射.心`：映射读写、整数值、字符串值、遍历键数组、`长度`。
  - 同步改 `源/运行时/运行时辅助.c` 映射容量 256→1024（宿主也受益，避免两链行为分叉），重建 日月.exe。
  - host vs 自举 输出一致；`make 自举` 不动点；`test_all23.ps1` 递增 1。

### Task S1.4: 匹配 + 枚举 + 元组

**Files:**
- Modify: `自举/词法.心`（关键字 匹配/枚举）、`自举/发射.心`（类型码 E/T、枚举/元组 IR）、`自举/语法.心`（匹配/枚举定义/枚举成员/元组字面量/元组访问）、`自举/编译器.心`（枚举/元组元数据表）

**Interfaces:**
- Produces: 类型码 `E`/`T`；枚举=编译期 i32（`枚举名::成员` 常量）；元组=具名 struct + 栈 alloca、按作用域绑定（怪癖 5）；匹配=顺序 icmp/strcmp 链，支持整数常量/字符串常量/`_`/绑定（怪癖 7）。

- [ ] **Step 1: 枚举**
  关键字 `枚举`；定义 `枚举 名{成员[,成员=整数]}` → 成员值表（键 `枚举名::成员名`）。`名::成员` → 编译期 i32 常量。怪癖 8 延后：显式值仅整数字面量（不额外处理负值）。

- [ ] **Step 2: 元组 + 作用域绑定（怪癖 5）**
  字面量 `(a,b,c)`（首元素后逗号）→ 具名 struct alloca。声明时登记 元组类型映射（**作用域**：跟随 局部表 生命周期，离开作用域删除）。元组访问 `.0` → GEP+load。整体重新赋值：目标变量是元组且 RHS 是元组字面量 → 逐成员 store（本计划按裁定支持）。

- [ ] **Step 3: 匹配（怪癖 7）**
  `匹配(表达式){ 整数常量=>{…} | "字符串"=>{…} | _=>{…} }`。顺序链：整数常量 → `icmp eq`；字符串常量 → `strcmp`+`icmp eq`；`_` → 无条件分支。绑定：`名=>{…}`（任意标识符作绑定，变量在分支内取匹配值）——首版仅支持「绑定时匹配值同时是 i32 或字符串」。

- [ ] **Step 4: 验证**
  - 新建 `示例/容器匹配.心`、`示例/容器元组.心`、`示例/容器枚举.心`：三种容器演示 + 打印。
  - host vs 自举 输出一致；`make 自举` 不动点；`test_all23.ps1` 递增 3。
