# 设计规格：变量声明类型默认规则 + 定宽整数/浮点类型

日期：2026-10-08
状态：已批准（用户 m0278「继续」）

## 1. 背景与目标

当前 日月 语言只有 整数/浮点/字符串/布尔 等基础类型名，其中 整数 固定映射 i32、浮点 映射 double。
变量声明 `值 = 变量 名;` / `值 = 名;` 只能在变量名一侧写类型，值一侧无法标注类型；两侧都不写类型时也没有明确的默认类型规则。

本规格：
1. 新增定宽整数类型 整数8/整数16/整数32/整数64 与定宽浮点类型 浮点32/浮点64；
2. 允许在「值」一侧标注类型；
3. 明确「值」与「变量名」两侧类型的优先级与一致性规则；
4. 明确两侧都无类型时的默认类型（默认类型兼容性要高）；
5. 明确混合宽度运算的提升规则与转换方式。

## 2. 类型词汇

| 类型名 | 底层 IR | 说明 |
|---|---|---|
| 整数8 | i8 | 有符号 8 位整数 |
| 整数16 | i16 | 有符号 16 位整数 |
| 整数32 | i32 | 有符号 32 位整数 |
| 整数64 | i64 | 有符号 64 位整数 |
| 浮点32 | float | 32 位浮点 |
| 浮点64 | double | 64 位浮点 |
| 整数 | i32 | 别名 ≡ 整数32（保持向后兼容） |
| 浮点 | double | 别名 ≡ 浮点64（保持向后兼容） |

说明：
- 现有代码中所有 整数 用法保持 i32 语义不变；所有 浮点 用法保持 double 语义不变。
- 新增类型名是独立的关键字级类型名，按字面匹配；类型别名机制（`原始类型 = 别名:类型;`）与本新增词汇并存，别名最终解析到上述基础类型之一。

## 3. 变量声明语法

统一形式：

```
值 [:类型] = [变量] 名 [:类型] ;
```

- 全局变量：`值 [:类型] = 变量 名 [:类型] ;`
- 局部变量：`值 [:类型] = 名 [:类型] ;`
- 「值」一侧类型标注为新增语法（值表达式后紧跟 `:类型`）。

## 4. 类型规则（优先级从高到低）

| 情形 | 值一侧 | 名一侧 | 结果 |
|---|---|---|---|
| a | 无类型 | 有类型 | 以名侧类型为准，值按需转换（窄←宽 截断，宽←窄 符号扩展；整数↔浮点 转换） |
| b | 有类型 | 无类型 | 名继承值侧类型 |
| c | 有类型 | 有类型 | 必须一致，否则编译错误（禁止隐式不一致） |
| d | 无类型 | 无类型 | 按值字面量种类取默认类型（见第 5 节） |

## 5. 默认类型参考表（两侧均无类型时）

| 值字面量/表达式种类 | 默认类型 |
|---|---|
| 整数字面量（如 `0`、`42`、`-1`） | 整数32 |
| 浮点字面量（如 `3.14`、`0.0`） | 浮点64 |
| 字符串字面量（如 `"abc"`） | 字符串 |
| 真 / 假 | 布尔 |

说明：
- 默认类型「兼容性要高」指：整数默认取 32 位（既能表达普通整数范围又不浪费），浮点默认取 64 位（精度最高）。
- 非字面量表达式（如函数调用结果）两侧均无类型时：以表达式静态类型为准（函数返回类型、已声明变量类型等），若仍无法确定则编译错误。

## 6. 算术与比较提升规则

- 同族（整数族 / 浮点族）二元运算：提升到较宽操作数类型（`整数8 + 整数32` → `整数32`；`浮点32 + 浮点64` → `浮点64`）。
- 跨族：`整数族 + 浮点族` → 浮点64（整数先 `sitofp` 转 浮点64，再运算）。
- 比较、赋值、解构沿用同一规则。
- 一元取负/正负号：保持操作数类型。

## 7. 转换规则

| 方向 | 转换指令 |
|---|---|
| 整数族 窄→宽 | 有符号扩展（`符号扩展` sext） |
| 整数族 宽→窄 | 截断（`截断` trunc） |
| 整数 → 浮点 | `有符号转浮点` sitofp |
| 浮点 → 整数 | `浮点转有符号` fptosi（截断式） |

## 8. 打印格式

打印 按表达式类型选择格式：
- i8 / i16：先符号扩展到 i32，再用 `%d`；
- i32：`%d`；
- i64：`%lld`；
- float（浮点32）：`%f`；
- double（浮点64）：`%g`。
