# PEG 内核用法

工具目录 `工具/peg/` 提供一套 PEG 解析器生成工具，输入一份「文法文件」即可：

- **解释模式**（`识别`）：按文法对输入文本做词法分析并解析，输出通用语法树（CST）。
- **生成模式**（`生成`）：把文法编译成一份 日月 语言写的递归下降解析器源码，编译后可独立解析。

## 文件构成

| 文件 | 职责 |
|------|------|
| `词法.心` | 正则子集匹配器（`正则匹配(文本, 模式, 起始)` 返回结束位置或 -1） |
| `文法.心` | 读取文法文件，解析 `%token/%keyword/%skip` 与规则表 |
| `匹配.心` | 分词 + PEG 通用匹配器（有序选择/序列/重复/前瞻），产出 CST |
| `生成.心` | 由文法生成 日月 递归下降解析器源码 |
| `主程序.心` | 命令行入口 `识别` / `生成` |

## 命令行

```
peg_cli  识别 <文法文件> <输入文件>          # 打印 CST（首行为 token 数）
peg_cli  生成 <文法文件> <输出.心>            # 生成解析器源码
```

生成的解析器自身接受两个参数：`<文法文件> <输入文件>`，运行时读取文法并解析输入，输出 CST。

## 文法文件语法

```
# 词法指令
%token 整数   [0-9]+
%token 标识符 [A-Za-z_][A-Za-z0-9_]*
%keyword 如果
%skip 空白    [ \t\r\n]+

# 规则（PEG）
程序 = 加减
加减 = 乘除 ('+' 乘除)*
乘除 = 原子 ('*' 原子)*
原子 = 整数 / 标识符 / ('(' 加减 ')')
```

- 注释：以 `#` 或 `//` 开头的行。
- `%token 名 正则`：定义词法记号；`名` 用作文法里的终结符。
- `%keyword 词`：定义关键字。
- `%skip 名 正则`：定义在词法阶段被跳过的空白/注释。
- 规则：`名 = 表达式`。

### PEG 表达式运算符（优先级由低到高）

| 语法 | 含义 |
|------|------|
| `a / b` | 有序选择：先试 `a`，失败再试 `b` |
| `a b c` | 序列（以空白分隔） |
| `e *` `e +` `e ?` | 重复 0+ / 1+ / 可选 |
| `&e` `!e` | 正/负前瞻（不消费） |
| `(...)` | 分组 |
| `'字面量'` `"字面量"` | 匹配单个 token 的文本 |
| `规则名` `%token 名` | 规则引用 / 终结符（按 token 类型匹配） |
| `.` | 任意一个 token |
| `标签:项` | 具名子节点 |
| `{ 日月代码 }` | 语义动作（预留） |

## 示例

`工具/peg/示例/算术.文法` + `算术.输入`（内容 `1+2*3`）：

```
peg_cli 识别 工具/peg/示例/算术.文法 工具/peg/示例/算术.输入
```

输出：

```
5
(程序 (加减 (乘除 (原子 1)) + (乘除 (原子 2) * (原子 3))))
```

```

```

依次验证：host 链的解释模式、生成模式（生成→编译→运行），以及自举链（`阶段/一级.exe`）的解释/生成，并比对 host 与自举生成的解析器源码是否一致。

## 当前限制

- 语义动作 `{...}` 在解释模式下暂不执行（解释模式统一产出通用 CST）；生成模式下动作原样保留，留待后续实现求值。
- 生成模式的 `%token` 终结符按 token 类型匹配；字面量按 token 文本匹配。
