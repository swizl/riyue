# 日月编程语言

一门**中文关键字、中文标识符、中文文件名**的**自举编译型语言**。后端输出**中文 LLVM IR 文本**（使用随仓库自行构建的本地化 LLVM 23）。

- 源码（编译器 + 标准库 + 示例）全部为中文文件名、中文标识符、中文关键字。
- 双编译器闭环：宿主种子 `引导.exe` 编译自举源码 `自举/主入口.心` 产出 `日月.exe`，且满足自举不动点。

## 环境配置

### 1. 本地化 LLVM 23

编译器与后端依赖一份**本地化**的 LLVM 23 构建（源码 fork 自 `swizl/llvm-project`，IR 关键字已汉化）。
将其构建于 `D:\src\riyue\llvm\llvm-build`，该目录需提供 `bin/clang++`、`bin/clang`、`bin/llvm-as`、`bin/llc`、`bin/ld.lld`、`bin/llvm-config`。

`Makefile` 默认使用该构建的 `llvm-config` 与 `clang++`，可用 `make LLVM_CONFIG=... CXX=...` 覆盖。

### 2. MSYS2 / MinGW-w64

从 https://www.msys2.org/ 安装 MSYS2（默认 `C:\tools\msys64`），并安装 MinGW-w64 工具链，以提供链接所需的 `mingw64/lib/crt2.o`、`dllcrt2.o` 及 `libmingw32` 等库。

### 3. 前置 PATH

编译/链接前，把本地化 LLVM 与 MSYS2 的 mingw64 置于 PATH 前部：

```bash
export PATH=/d/src/riyue/llvm/llvm-build/bin:/c/tools/msys64/mingw64/bin:$PATH
```

## 编译

日月有**两条编译链**：

| 编译器 | 来源 | 说明 |
|---|---|---|
| `引导.exe`（约 48 MB） | 由 `源/*.cpp` 用本地化 `clang++` 构建 | 宿主**种子**编译器，功能最全（含 `--调试`/`--优化`/`--运行`/REPL 等） |
| `日月.exe`（约 1.1 MB） | 由 `引导.exe` 编译 `自举/主入口.心` 产出 | **自举**主编译器 |

### 方式一：Makefile

```bash
make           # 默认目标：先建 引导.exe，再自举出 日月.exe
make 引导       # 仅构建种子 引导.exe（会一并生成 源/运行时/运行时辅助.o）
```

### 方式二：手动

```bash
# 1) 构建种子（顺带生成运行时目标文件 源/运行时/运行时辅助.o）
make 引导

# 2) 用种子自举出主编译器
PATH=/d/src/riyue/llvm/llvm-build/bin:/c/tools/msys64/mingw64/bin:$PATH \
  ./引导.exe 自举/主入口.心 日月.exe
```

> `日月.exe` 编译产物时会复制 `源/运行时/运行时辅助.o` 参与链接，故该文件必须先存在（`make 引导` 会生成）。

## 运行

### 日月.exe（自举主编译器）

接受「`--调试`(可选) 输入 输出」，产物类型由**输出扩展名**决定：

```
日月.exe 输入.心 输出.ll     # 输出中文 LLVM IR 文本
日月.exe 输入.心 输出        # 编译并用 ld.lld 链接为原生可执行文件
日月.exe 输入.心 输出.dll    # 生成 Windows 动态库（ld.lld -m i386pep --dll）
日月.exe 输入.心 输出.so     # 生成 ELF 共享库（ld.lld -m elf_x86_64 --shared）
日月.exe --调试 输入.心 输出 # 额外发射中文 DWARF 调试信息（!dbg，供 gdb 源码级调试）
日月.exe --优化[=级别] 输入.心 输出 # 中端优化（级别 0..3，省略=2；亦可 -O0..-O3；Os 回退 -O2）
```

`--调试` 关闭时输出**逐字节不变**；开启时发射与宿主等价的 `!编译单元/!文件/!子程序/!局部变量/!位置` 等中文元数据，`llvm-as`/`llvm-dis`/`llc` 全链路可往返，`gdb` 可按源码行下断点、`info locals` 与 `print` 查看变量。

`--优化[=级别]` 在 `llvm-as` 之后、`llc` 之前插入 `opt -O{级别}`（真正做中端内联/循环优化），并给 `llc` 传 `-O{级别}`；级别 `> 0` 时产出的仍是**全中文** IR（可 `llvm-as`/`llvm-dis`/`opt`/`llc` 往返）。`--优化`（不带级别）等价 `--优化=2`。

链接层一律使用本地化 `ld.lld`：可执行文件 `-m i386pep` + `crt2.o`，Windows 动态库 `-m i386pep --dll` + `dllcrt2.o`，并链入 `源/运行时/运行时辅助.o` 与 MSYS2 的 mingw 库。

### 引导.exe（宿主种子）

功能更全，用法：

```
引导.exe [--调试] [--优化[=级别]|-O0..-O3|-Os] 输入.心 输出   # 编译为原生可执行文件（优化开关须前置）
引导.exe --运行 输入.心                        # 虚拟机直接运行
引导.exe --字节码 输入.心 输出.riue            # 编译为字节码
引导.exe --执行 输出.riue                      # 执行字节码文件
引导.exe --交互                                # 交互式 REPL
```

## 测试与护栏

```bash
bash run_tests.sh      # 或 make 测试
```

- 遍历 `示例/*.心`（共 **92** 个用例）：逐个编译并运行，与 `示例/<名>.期望` 比对输出；无 `.期望` 的用例仅要求编译成功且退出码为 0（当前 39 个用例带期望快照）。
- **`.期望错` 用例**（当前 4 个）：期望运行期「被拦截并中止」（如数组越界）——须编译成功、运行以非零码退出、且 stderr（去空行/去 `\r` 后）等于 `示例/<名>.期望错` 内容。
- 结果打印到控制台，同时固化到 `阶段/回归.log`。
- 末尾按**门禁**判定退出码：`Pass ≥ 92 且 Fail = 0` 才算通过（返回 0），否则返回非 0。
- 脚本会清理并终止残留的 `日月/out_t/clang++/ld/llc` 进程；**切勿并发**运行编译或测试。
- 需要并行提速时用 `JOBS=8 bash 阶段/gate/回归并行.sh`：为每个 worker 分配独立工作目录（内含 `源/示例/标准库` 三个 junction 指回仓库）以规避链接临时文件（基于 `%RANDOM%`）撞名，语义与 `run_tests.sh` 对齐（`Pass ≥ 92` 且 `Fail = 0`），约 5× 提速；结果写 `阶段/回归并行.log`。

## 自举不动点

```bash
bash 不动点验证.sh     # 直接验证（推荐）
make 自举              # 等价；会先确保种子 引导.exe 最新
```

链路：`引导.exe` → `阶段/一级.exe` → `阶段/中间码1.ll` →（`llvm-as`/`llc`）→ `阶段/中间码1.o` →（`ld.lld`）→ `阶段/二级.exe` → `阶段/中间码2.ll`。

判定：`阶段/中间码1.ll` 与 `阶段/中间码2.ll` **完全一致**（SHA256 相同）即自举闭环成立。证据（两份中间码的字节数与哈希，不一致时的 diff）固化到 `阶段/不动点.log`。

> `make 自举` 依赖种子 `引导.exe`：若其 `.o` 缺失会触发宿主重建，需 `clang++` 与其依赖（`libzstd.dll`，在 MSYS2 的 `mingw64/bin`）在 PATH 中；仅做不动点验证时直接用上面的脚本即可（脚本不重建种子）。

## 性能基准

```bash
bash 基准/跑基准.sh      # 对比 --优化=0/2/3 的运行耗时，结论写 阶段/基准.log
```

- 基准程序 `基准/基准测试.心`：递归 `斐波那契(32)` + 三段各 **2 亿**次循环（取模累加 / 数组求和 / 函数调用累加），输出固定四行。
- 脚本用 `日月.exe` 分别编 `--优化=0/2/3`，**预热 1 次后取 7 轮最小值**（冷启动受杀软/磁盘干扰极大），核对三档输出一致后用 `awk` 算倍率。
- 实测（本机）：`-O0` 1380 ms，`-O2/-O3` 749 ms ⇒ **`--优化=2` 相对 `-O0` 提速约 1.84×**；提速主要来自循环段（中端内联/循环优化/`alloca` 提升），递归段在 `-O2` 下基本不提速。
- 注意：`基准/` **不进** `示例/`，故不影响 `run_tests.sh` 的 `MIN_PASS=92` 门禁。

## 语言特性

> **赋值方向为「值在左、目标在右」**：`值 = 目标;` 表示把左边的值赋给右边的变量。声明变量同样写作 `值 = 变量名;`。
> **函数名为「参数在左、名字在右」**，**调用为后缀式** `(实参, ...)函数名`。
> 更多可运行示例见 `示例/*.心`。

### 变量、常量与赋值

```c
42 = 变量值;             // 声明 变量值 并初始化为 42
变量值 + 1 = 变量值;      // 变量值 += 1（无复合赋值运算符，直接重写）
"你好世界" = 文本;        // 字符串
3.14 = 浮点数;            // 浮点数
真 = 真值;                // 布尔
3 = 常量 PI;              // 常量声明（不可再赋值）
```

### 函数与调用

返回值为**出参**：写在函数名后的括号里，形如 `初值 = 名:类型`。

```c
函数 (数量:整数)阶乘(1 = 结果:整数) {
    如果 (数量 <= 1) {
        1 = 结果;
    } 否则 {
        数量 - 1 = 前一个;
        (前一个)阶乘 = 递归结果;
        数量 * 递归结果 = 结果;
    }
}

函数 主程序 {
    (10)阶乘 = r1;        // 调用，结果赋给 r1
    (r1)打印;
}
```

**省略括号规则**：无入参可省略前括号、无返回值可省略后括号。

```c
函数 打招呼 { ("你好")打印; }          // 前后都省略

函数 取数(7 = 结果:整数) { 7 = 结果; }  // 仅省略前括号

函数 (值:整数)打印值 { (值)打印; }      // 仅省略后括号

函数 (甲:整数, 乙:整数)相加(0 = 结果:整数) { 甲 + 乙 = 结果; }  // 都不省略
```

```c
()打招呼;
()取数 = 数;
(5)打印值;
(3, 4)相加 = 和;
```

**多返回值**：出参可多个，调用侧用元组接收。

```c
函数 (甲:整数, 乙:整数)交换(0 = 变量值:整数, 0 = y:整数) {
    乙 = 变量值;
    甲 = y;
}
(10, 3)交换 = (变量值, y);
```

### 控制流

```c
如果 (变量值 > 90) {
    ("优秀")打印;
} 否则如果 (变量值 > 80) {
    ("良好")打印;
} 否则 {
    ("及格")打印;

    索引 + 1 = 索引;

}
循环 (计数: 0, 10, 2) {    // 带步长
    (计数)打印;
}

遍历 (值 : arr) {           // for-in 遍历
    (值)打印;
}
```

### 运算符

| 运算符 | 含义 |
|--------|------|
| `+` `-` `*` `/` `%` | 算术（`+` 也用于字符串拼接） |
| `?=` `!=` `<` `>` `<=` `>=` | 比较（相等用 `?=`，不等用 `!=`） |
| `&&` `\|\|` `!` | 逻辑运算 |
| `? :` | 三元条件 |

## 已知限制

- **链接依赖 MSYS2 的 `crt2.o`/`dllcrt2.o` 与 mingw 库**，且路径按本机布局（`C:\tools\msys64`）写死；更换环境需同步调整。
- **中文名 DLL 无法被调用方加载**：DLL 会把自身文件名内嵌为「导入名」，Windows 加载器按 ANSI 解析，非 ASCII 名会报 `0xC0000135`。请用 **ASCII 名**导出 DLL。（`ld.lld` 能正确创建中文名 DLL，属平台加载器限制。）
- **不支持并发编译**：回归脚本会终止残留编译进程，且链接临时名基于 `%RANDOM%`，并发可能撞名互相删除（需要并行时用上面的 `回归并行.sh`，靠独立工作目录规避）。
- **优化档改变 IR 文本**：`--优化>0` 的产物经 `opt`，与默认档的 IR 文本不同（运行输出一致）。另：默认 IR 自「A+B 全汉化」后与更早版本**不再逐字节相同**，基线以 `阶段/基线.log` 为准。
- **优化收益有边界**：计算密集循环约 1.8×（见「性能基准」）；递归负载在 `-O2` 下基本不提速，`-O3` 与 `-O2` 相当；自举链 `-Os` 回退 `-O2`（LLVM 23 已移除 `-Os`）。
- **`引导.exe` 自身的链接仍由 `clang++` 驱动**（`源/后端/代码生成器.cpp`）；切换到 `ld.lld` 仅覆盖自举产物（`日月.exe` 的输出）。
- VM / 字节码模式（仅 `引导.exe --运行`）支持整数、浮点数、字符串、数组，但不支持文件 IO 与网络函数。
