# 日月编程语言

一门中文编程语言，支持中文关键字、变量名和文件名。

## 目录结构

```
日月/
├── 源/                  # 编译器源码（C++）
│   ├── 前端/            # 词法分析器、语法分析器、AST
│   ├── 后端/            # LLVM IR 代码生成器、符号表
│   ├── 虚拟机/          # 字节码定义、字节码编译器、虚拟机
│   ├── 运行时/          # 运行时辅助函数（C）
│   └── 主程序.cpp       # 编译器入口
├── 语法/                # 语法定义文件
├── 示例/                # 日月语言示例程序（.心 文件）
├── 测试/                # 单元测试和集成测试
├── 工具/                # 解析器生成器等工具
├── 自举/                # 三级自举相关文件
├── 构建/                # 编译产物（已 gitignore）
├── 文档/                # 文档
├── Makefile             # 构建脚本
└── README.md            # 本文件
```

## 环境配置

### 1. 安装 MSYS2

从 https://www.msys2.org/ 下载并安装 MSYS2。

安装后打开 MSYS2 MinGW 64-bit 终端，执行：

```bash
pacman -Syu
pacman -S mingw-w64-x86_64-clang mingw-w64-x86_64-llvm mingw-w64-x86_64-make
```

### 2. 配置 PATH

确保 MSYS2 的 mingw64 bin 目录在 PATH 中：

```bash
export PATH=/mingw64/bin:$PATH
```

### 3. 验证环境

```bash
clang++ --version
llvm-config --version
make --version
```

## 编译

### 方式一：使用 Makefile（推荐）

```bash
# 在 MSYS2 MinGW 64-bit 终端中
cd /d/src/lune2

# 编译日月编译器
make

# 或者直接运行
make 运行
```

### 方式二：手动编译

```bash
cd /d/src/lune2

# 编译所有源文件
clang++ -std=c++17 -Wall -Wextra -g \
  -finput-charset=UTF-8 -fexec-charset=UTF-8 \
  -I/mingw64/include \
  -D_GNU_SOURCE -D__STDC_CONSTANT_MACROS \
  -D__STDC_FORMAT_MACROS -D__STDC_LIMIT_MACROS \
  -c 源/主程序.cpp -o 构建/主程序.o

# 对其他源文件重复上述步骤...

# 链接
clang++ -g -L/mingw64/lib -o 日月.exe \
  构建/主程序.o 构建/词法分析器.o 构建/语法分析器.o \
  构建/代码生成器.o 构建/字节码.o 构建/字节码编译器.o \
  -lLLVM-22 -lshell32
```

## 运行

### 命令行用法

```
日月.exe [--调试] [--优化] 输入文件.心 输出文件    (编译为原生可执行文件)
日月.exe --运行 输入文件.心               (虚拟机直接运行)
日月.exe --字节码 输入文件.明 输出.riue   (编译为字节码)
日月.exe --执行 输出.riue                (执行字节码)
日月.exe --交互                         (交互式REPL)
```

### 优化选项

使用 `--优化` 标志可以启用编译器优化，包括：
- **尾递归优化**：将尾递归调用转换为循环，避免栈溢出
- **死代码消除**：删除不可达的代码块和无用指令
- **内联优化**：将小函数内联展开
- **循环优化**：循环不变量外提等
- **内存到寄存器提升**：减少内存访问
- **指令组合**：合并和简化指令
- **全局值编号**：消除冗余计算

```bash
# 启用优化编译
./日月.exe --调试 --优化 示例/递归测试.心 构建/递归测试_opt.exe
./构建/递归测试_opt.exe
```

### 示例

```bash
# LLVM 编译模式（推荐，支持所有功能）
./日月.exe --调试 示例/控制流.心 构建/控制流.exe
./构建/控制流.exe

# 虚拟机模式（仅支持整数运算）
./日月.exe --运行 示例/控制流.心

# 运行示例程序
./日月.exe --调试 示例/浮点数.心 构建/浮点数.exe && ./构建/浮点数.exe
./日月.exe --调试 示例/文件IO.心 构建/文件IO.exe && ./构建/文件IO.exe
./日月.exe --调试 示例/递归测试.心 构建/递归测试.exe && ./构建/递归测试.exe
```

# 运行完整测试套件

## 语言特性

### 基本类型

```c
变量 整数值 = 42;          // 整数
变量 浮点值 = 3.14;        // 浮点数
变量 真值 = 真;            // 布尔值
变量 假值 = 假;            // 布尔值
变量 文本 = "你好世界";    // 字符串
```

### 函数

```c
函数 阶乘(数): 整数 {
    如果 (数 <= 1) {
        返回 1;
    }
    返回 数 * 阶乘(数 - 1);
}
```

### 控制流

```c
// 条件语句
如果 (值 > 90) {
    打印("优秀");
} 否则如果 (值 > 80) {
    打印("良好");
} 否则 {
    打印("及格");
}

// 当循环
变量 计数 = 0;
当 (计数 < 10) {
    计数 = 计数 + 1;
    如果 (计数 % 2 ?= 0) {
        继续;
    }
    打印(计数);
}
```

### 数组

```c
变量 数据 = [10, 20, 30, 40, 50];
打印(数据[0]);      // 10
数据[2] = 99;        // 修改元素
```

### 闭包

```c
变量 基数 = 100;
变量 加基数 = 函数(值): 整数 {
    返回 值 + 基数;
};
打印(加基数(50));    // 150
```

### 文件 IO

```c
变量 文件 = 打开("输出.txt", "w");
写入(文件, "你好\n");
写入(文件, 42);
关闭(文件);
```

### 字符串操作

```c
变量 a = "你好";
变量 b = "世界";
变量 c = a + b;          // 拼接："你好世界"
打印(长度(c));           // 长度：12
打印(查找(c, "世界"));   // 查找位置：6
打印(子串(c, 2, 3));     // 子串
打印(转字符串(42));       // 转字符串："42"
打印(替换("aabaa", "b", "c"));  // 替换："aacaa"
```

### 数学函数

```c
打印(绝对值(-42));       // 42
打印(绝对值(3.14));      // 3.14
打印(最小值(10, 20));    // 10
打印(最大值(10, 20));    // 20
打印(最小值(3.14, 2.72)); // 2.72
打印(最大值(3.14, 2.72)); // 3.14
```

### 类型转换

```c
打印(类型(42));          // "整数"
打印(类型(3.14));        // "浮点数"
打印(类型("hello"));     // "字符串"
打印(转整数(3.14));      // 3
打印(转浮点(42));        // 42.0
```

### 字符串插值

```c
变量 名字 = "世界";
变量 年龄 = 25;
打印(f"你好，{名字}！");       // 你好，世界！
打印(f"年龄：{年龄}岁");       // 年龄：25岁
打印(f"明年{年龄 + 1}岁");     // 明年26岁
```

### 字符串数组

```c
变量 水果 = ["苹果", "香蕉", "橙子"];
打印(水果[0]);          // 苹果
水果[1] = "葡萄";       // 修改元素
遍历(项 : 水果) {       // 遍历字符串数组
    打印(项);
}
```

### 常量

```c
常量 圆周率 = 3;
打印(圆周率);           // 3
// 圆周率 = 4;          // 编译错误：不能对常量赋值
```

### 文件读取字符串

```c
打开("数据.txt", "r");
变量 行 = 读取行();      // 读取一行文本
关闭(0);
打印(行);
```

### for 循环

```c
循环 (变量 i = 0; i < 10; i += 1) {
    打印(i);
}
```

### match 语句

```c
变量 x = 2;
匹配 (x) {
    1 => { 打印("一"); }
    2 => { 打印("二"); }
    _ => { 打印("其他"); }
}
```

### for-in 循环

```c
变量 arr = [10, 20, 30];
遍历 (v : arr) {
    打印(v);
}
```

### 映射/字典

```c
变量 m = ["姓名": "张三", "年龄": "25"];
打印(m["姓名"]);    // 张三
打印(m["年龄"]);    // 25
```

### 模块系统

```c
// 数学模块.心
函数 加法(甲, 乙): 整数 {
    返回 甲 + 乙;
}

// 主程序.心
导入 "数学模块.心";

函数 主程序(): 空 {
    打印(加法(10, 20));  // 30
}
```

### 运算符

| 运算符 | 含义 |
|--------|------|
| `+` `-` `*` `/` `%` | 算术运算（+也用于字符串拼接） |
| `?=` `!=` `<` `>` `<=` `>=` | 比较运算（?用于字符串比较） |
| `&&` `\|\|` `!` | 逻辑运算 |
| `+=` `-=` `*=` `/=` | 复合赋值 |

## 已知限制

- LLVM 模式（`--调试`）支持所有功能，推荐使用
- VM 模式（`--运行`）支持整数、浮点数、字符串、数组，但不支持文件IO和网络函数
