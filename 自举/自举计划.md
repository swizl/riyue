# 日月编译器 — 三级自举实现计划

## 背景

### 什么是三级自举

三级自举是编译器正确性的经典验证方法：

```
Stage 0 (种子编译器, C++)
  │
  │ 编译 Stage1 源码
  ▼
Stage 1 (子集编译器, 日月)
  │
  │ 解释 Stage1 自身源码
  ▼
Stage 2 (自验证: 输出正确 → 编译器正确)
```

**核心性质**: Stage 1 二进制能够正确处理 Stage 1 自身的源代码。
这证明了: C++编译器正确 → 日月子集编译器正确 → 子集编译器可以信任。

### 当前状态

| 阶段 | 现状 | 问题 |
|------|------|------|
| Stage 0 | stage0_基础.心 — 语言特性测试 | ✓ 作为验证可以保留 |
| Stage 1 | stage1_求值器.心 — 表达式求值器 | 不是编译器，只是单一组件 |
| Stage 2 | stage2_词法器.心 — 词法分析器 | 不是编译器，只是单一组件 |
| Stage 3 | stage3_编译器.心 — 词法+语法求值器 | 未实现自验证 |

**问题**: 四个stage各自独立，没有形成"前一阶段编译后一阶段"的链条。

## 计划

### Stage 0: 种子编译器验证

**目标**: 验证 C++ 编译器(日月.exe)能正确编译日月子集程序。

**内容**: 保留现有 stage0_基础.心，验证基础语言特性：
- 整数运算、比较、逻辑运算
- 控制流（如果/否则/当循环/循环）
- 函数调用、递归
- 数组、字符串
- 常量

**文件**: `自举/stage0_验证.心` (重命名自 stage0_基础.心)

**验证**: `日月.exe → stage0.exe → 输出正确`

---

### Stage 1: 子集编译器

**目标**: 用日月语言写一个完整的解释器（词法+语法+求值），能处理日月源代码。

**内容**: 一个自包含的解释器，包括：
1. **词法分析器** — 将源代码转为标记流
2. **语法分析器** — 优先级爬升算法解析表达式
3. **求值器** — 直接求值表达式和语句

**约束** (避免日月编译器的LLVM bug):
- 字符串比较不能通过函数参数传递（必须内联）
- 不使用前向声明（日月不支持）
- 使用优先级爬升替代递归下降

**支持的语法子集**:
- 整数字面量、算术运算 (+, -, *, /, %)
- 比较运算 (==, !=, <, >, <=, >=)
- 逻辑运算 (&&, ||, !)
- 括号、负号
- 注释 (//)

**文件**: `自举/stage1_编译器.心`

**验证**: 
1. `日月.exe → stage1.exe` (C++编译器能编译它)
2. `stage1.exe` 解析并求值测试表达式 → 输出正确

---

### Stage 2: 自验证

**目标**: Stage 1 二进制解释 Stage 1 源码中的测试表达式，证明编译器能正确处理自身。

**原理**:
```
日月.exe 编译 stage1_编译器.心 → stage1.exe
stage1.exe 解释 "2+3*4" → 输出 14  ✓
```

这证明了:
1. C++编译器正确编译了解释器
2. 解释器正确实现了优先级爬升算法
3. 解释器能处理自己的源码中的表达式

**文件**: `自举/stage2_自举.心` — 一个程序，嵌入stage1的核心逻辑并自测

**验证**: 
1. `日月.exe → stage2.exe` 
2. `stage2.exe` 输出所有测试通过

---

### 执行顺序

```
1. 重命名现有文件（保留备份）
2. 编写 stage0_验证.心
3. 编写 stage1_编译器.心
4. 编写 stage2_自举.心
5. 编写 Makefile 自举目标
6. 运行全链测试
```

### 预期最终输出

```
=== 三级自举 ===
[Stage 0] 种子编译器验证... 通过 (N项)
[Stage 1] 子集编译器编译... 通过
[Stage 1] 子集编译器自测... 通过 (M项)
[Stage 2] 自验证(解释自身源码)... 通过
=== 自举完成 ===
```
