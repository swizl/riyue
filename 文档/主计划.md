```bash
make                # 宿主 C++ 编译器（引导.exe）
make 日月.exe       # 自举编译器（需先 make）
make 自举           # 不动点：stage1 → ir1 → stage2 → ir2 → diff
make clean          # 清理
./run_tests.sh      # Bash 全量回归（87 用例，比对 .期望）
./test_all23.ps1    # PowerShell 全量测试（现状：仅判 rc）
```

### 环境

- **OS**: Windows（MSYS2 MinGW64 bash，**勿用 Git Bash**）
- **PATH**: `llvm-build/bin` + `mingw64/bin`（须前置 mingw64，否则 DLL 冲突）
- **环境变量**: `MSYS2_ARG_CONV_EXCL='*'`
- **不并发编译**：`run_tests.sh` 清理逻辑会杀 `日月` / `clang++` / `ld` / `llc`
