**框架化原则**（与项目既有约定一致）：
1. 骨架一律**纯 `.心`** 或独立脚本，**不改自举源** ⇒ 自举不动点恒定、回归不退化。
2. 骨架内**不调用尚未登记的内建**（避免宿主链/自举链解析失败）；确需依赖的在文件头注明依赖与阻塞点。
3. 骨架登记进 `标准库/所有.心` 者随 `make 标准库冒烟` 一并编译校验。

## Phase 5：迭代器与生成器（1-2 周）

### 5.1 迭代器协议
- `下一个()` 方法返回下一个元素
- `结束()` 判断是否结束
- 内置数组/映射/字符串迭代器

### 5.2 生成器语法
```
函数 (开始, 结束)范围(让出: 整数) {
    遍历 (索引: 开始, 结束) {
        索引 = 让出;
    }
}
```

### 5.3 集合操作
- `映射(数组, 函数)` — 惰性映射
- `过滤(数组, 条件)` — 惰性过滤

- 链式调用支持
