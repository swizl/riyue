- `外部 函数` 声明语法
- 基本类型映射（int/float/char*）
- 结构体传递
- 函数指针回调
- 动态库加载（dlopen/LoadLibrary）

### 4.2 语法设计
```
// 声明外部函数
外部 函数 (路径: 字符串)打开文件(模式: 字符串): 整数;

// 使用外部结构体
外部 结构体 文件状态 {
    设备ID: 整数;
    大小: 整数;
}
```

## Phase 5：迭代器与生成器（1-2 周）

### 5.1 迭代器协议
- `下一个()` 方法返回下一个元素
- `结束()` 判断是否结束
- 内置数组/映射/字符串迭代器

### 5.2 生成器语法
```
函数 (开始, 结束)范围(让出: 整数) {
    遍历 (索引: 开始, 结束) {
        索引 = 让出;
    }
}
```

### 5.3 集合操作
- `映射(数组, 函数)` — 惰性映射
- `过滤(数组, 条件)` — 惰性过滤
- `折叠(数组, 初始值, 函数)` — 归约
- 链式调用支持
