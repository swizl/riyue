# 日月语言短板补齐计划

## 概述

基于与 C++/Rust/Go/Python 的差距分析，按优先级分阶段补齐短板。

---

## Phase 1：标准库扩充（2-3 周）

### 1.1 网络库
- HTTP 客户端（GET/POST/Header/Cookie）
- HTTP 服务端（路由、中间件）
- WebSocket 支持
- DNS 解析

### 1.2 数据结构
- 链表（单向/双向）
- 队列/双端队列
- 优先队列（堆）
- 集合（基于哈希/有序）
- 树（二叉搜索树/AVL/B树）

### 1.3 加密与哈希
- MD5/SHA1/SHA256
- Base64 编解码
- AES 加解密
- HMAC

### 1.4 序列化
- JSON 完整解析/生成（当前仅有基础）
- CSV 解析/生成
- 二进制序列化

### 1.5 系统调用
- 进程管理（创建/等待/退出）
- 环境变量读写
- 信号处理

---

## Phase 2：包管理器完善（2 周）

### 2.1 核心功能
- 包注册表（本地/远程仓库）
- 语义化版本管理
- 依赖解析（版本冲突检测）
- 包锁定文件（类似 package-lock.json）
- 包安装/卸载/更新/搜索

### 2.2 包结构规范
```
包名/
  ├── 包信息.心       # 包元数据（名称/版本/依赖）
  ├── 源/             # 源码
  ├── 示例/           # 示例代码
  ├── 测试/           # 测试代码
  └── 文档/           # 文档
```

### 2.3 命令行工具
- `日月 包 安装 <包名>` — 安装包
- `日月 包 搜索 <关键词>` — 搜索包
- `日月 包 发布` — 发布包
- `日月 包 更新` — 更新依赖

---

## Phase 3：测试框架（1-2 周）

### 3.1 测试运行器
- 自动发现测试文件
- 测试套件/测试用例组织
- 前置/后置钩子（setup/teardown）
- 测试过滤（按名称/标签）
- 并行测试执行

### 3.2 断言库
- 相等/不等/大于/小于断言
- 近似断言（浮点容差）
- 异常断言（期望抛出）
- 字符串包含/匹配断言

### 3.3 基准测试
- 函数执行时间测量
- 内存分配统计
- 多次运行取平均值

### 3.4 覆盖率
- 行覆盖率统计
- 分支覆盖率
- 覆盖率报告生成

---

## Phase 4：FFI 接口（2 周）

### 4.1 C 语言互操作
- `外部 函数` 声明语法
- 基本类型映射（int/float/char*）
- 结构体传递
- 函数指针回调
- 动态库加载（dlopen/LoadLibrary）

### 4.2 语法设计
```
// 声明外部函数
外部 函数 (路径: 字符串)打开文件(模式: 字符串): 整数;

// 使用外部结构体
外部 结构体 文件状态 {
    设备ID: 整数;
    大小: 整数;
}
```

---

## Phase 5：迭代器与生成器（1-2 周）

### 5.1 迭代器协议
- `下一个()` 方法返回下一个元素
- `结束()` 判断是否结束
- 内置数组/映射/字符串迭代器

### 5.2 生成器语法
```
函数 (开始, 结束)范围(让出: 整数) {
    遍历 (索引: 开始, 结束) {
        索引 = 让出;
    }
}
```

### 5.3 集合操作
- `映射(数组, 函数)` — 惰性映射
- `过滤(数组, 条件)` — 惰性过滤
- `折叠(数组, 初始值, 函数)` — 归约
- 链式调用支持

---

## Phase 6：IDE 支持（3-4 周）

### 6.1 LSP 服务端
- 语法高亮（词法标记）
- 自动补全（变量/函数/类型）
- 跳转定义（函数/变量/结构体）
- 查找引用
- 悬停提示（类型/文档）
- 诊断信息（错误/警告）
- 代码格式化

### 6.2 实现方式
- 独立进程通信（stdio/管道）
- 增量解析（缓存 AST）
- 基于现有语法分析器扩展

### 6.3 VS Code 插件
- 语法高亮配置
- 代码片段
- 任务配置（编译/运行）
- 调试器集成

---

## Phase 7：工具链增强（1-2 周）

### 7.1 代码格式化器
- 统一缩进（2空格/4空格/制表符）
- 运算符间距
- 换行规则
- 尾随逗号处理

### 7.2 文档生成器
- `/// 文档注释` 语法
- Markdown 生成
- 模块/函数/类型索引
- 示例代码提取

### 7.3 静态分析
- 未使用变量检测
- 不可达代码检测
- 潜在空指针警告
- 类型不匹配警告
