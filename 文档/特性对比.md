## 建议添加的特性（按优先级排序）

### 高优先级（核心功能）

1. **浮点数类型** ✓ 已完成
   - 添加 `浮点` 类型
   - 支持浮点字面量：`3.14`
   - 浮点运算：`+`, `-`, `*`, `/`
   - 打印格式：`%f`

2. **for循环** ✓ 已完成
   - 语法：`循环 (变量 i = 0; i < 10; i += 1) { ... }`

3. **字符串操作** ✓ 已完成
   - 字符串拼接：`"hello" + " world"`
   - 字符串长度：`长度("hello")` → 5
   - 字符串查找：`查找("hello world", "world")` → 6
   - 字符串子串：`子串("hello", 1, 3)` → "ell"
   - 转字符串：`转字符串(42)` → "42"

4. **结构体/类**
   - 语法：`结构体 点 { x: 整数; y: 整数; }`
   - 实例化：`变量 p = 点 { x: 10, y: 20 };`
   - 访问：`p.x`, `p.y`

### 中优先级（实用功能）

5. **for-in循环** ✓ 已完成
   - 语法：`遍历 (元素 : 数组) { ... }`

6. **switch/match语句** ✓ 已完成
   - 语法：`匹配 (值) { 1 => { ... }, 2 => { ... }, _ => { ... } }`

7. **映射/字典** ✓ 已完成
   - 语法：`变量 映射 = ["键1": 值1, "键2": 值2];`
   - 访问：`映射["键1"]`

8. **模块系统** ✓ 已完成
   - 语法：`导入 "文件名.心";`
   - 支持函数和结构体的导入

9. **异常处理**
   - 语法：`尝试 { ... } 捕获 (错误) { ... }`

10. **枚举类型**
    - 语法：`枚举 颜色 { 红, 绿, 蓝 }`

### 低优先级（高级功能）

11. **泛型**
    - 语法：`函数 最大值<T>(甲: T, 乙: T): T { ... }`

12. **并发**
    - 语法：`异步 函数 下载() { ... }`
    - 或者：`线程 { ... }`

13. **宏系统**
    - 语法：`宏 打印调试(表达式) { ... }`

14. **所有权系统**
    - 类似Rust的所有权和借用

15. **反射**
    - 运行时类型信息
    - 动态调用

## 语言设计建议

### 语法改进

1. **统一的类型注解**
   - 当前：`函数 阶乘(数): 整数 { ... }`
   - 建议：`函数 阶乘(数: 整数): 整数 { ... }`

2. **更自然的循环语法**
   - 当前：`当 (条件) { ... }`
   - 保持：`当 (条件) { ... }`
   - 添加：`循环 (变量 i = 0; i < 10; i += 1) { ... }`

3. **字符串插值**
   - 语法：`"值为: ${变量}"`

### 标准库建议

1. **数学库**
   - `绝对值(数)`, `最大值(甲, 乙)`, `最小值(甲, 乙)`
   - `随机数()`, `平方根(数)`

2. **字符串库**
   - `长度(字符串)`, `子串(字符串, 开始, 长度)`
   - `查找(字符串, 子串)`, `替换(字符串, 旧, 新)`

3. **数组库**
   - `排序(数组)`, `查找(数组, 元素)`
   - `过滤(数组, 条件)`, `映射(数组, 函数)`

4. **文件系统**
   - `存在(路径)`, `删除(路径)`, `重命名(旧, 新)`
   - `读取全部(路径)`, `写入全部(路径, 内容)`
