# 日月编译器架构文档

## 概述

日月是一门中文编程语言，编译器采用 C++17 实现，支持两种后端：
- **LLVM 后端**：编译为原生可执行文件（支持所有特性）
- **字节码虚拟机后端**：解释执行（支持整数、数组、字符串、闭包、结构体）

## 编译流程

```
源代码(.心)
    │
    ▼
┌──────────┐
│  词法分析  │  源/前端/词法分析器.cpp
└────┬─────┘
     │ 标记流
     ▼
┌──────────┐
│  语法分析  │  源/前端/语法分析器.cpp
└────┬─────┘
     │ AST
     ▼
┌──────────────────┬──────────────────┐
│   LLVM 代码生成    │   字节码编译 + VM   │
│  源/后端/          │  源/虚拟机/         │
└────┬─────────────┴────┬─────────────┘
     │                   │
     ▼                   ▼
  原生可执行文件       解释执行
```

## 目录结构

```
源/
├── 前端/                  # 词法分析、语法分析、AST 定义
│   ├── 公共.h             # 调试宏、全局配置
│   ├── 词法分析器.h/.cpp   # 词法分析器（UTF-8 支持）
│   ├── 语法分析器.h/.cpp   # 递归下降语法分析器
│   └── 抽象语法树.h        # AST 节点定义（表达式 + 语句）
│
├── 后端/                  # LLVM IR 代码生成
│   ├── 符号表.h           # 变量/函数/类型符号表
│   ├── 代码生成器.h/.cpp   # 主入口、函数生成、自由变量收集
│   ├── 代码生成器_语句.cpp  # 语句代码生成
│   ├── 代码生成器_表达式.cpp # 表达式代码生成（内置函数、运算符）
│   └── 代码生成器_内部.h    # 内部共享头文件（LLVM includes、工具函数）
│
├── 虚拟机/                # 字节码定义、编译器、虚拟机
│   ├── 字节码.h/.cpp       # 操作码定义、值类型、指令格式、序列化
│   ├── 字节码编译器.h/.cpp  # AST → 字节码编译器
│   └── 虚拟机.h/.cpp       # 寄存器虚拟机实现
│
├── 运行时/                # C 运行时辅助函数
│   └── 运行时辅助.c        # UTF-8 字符操作、映射辅助
│
└── 主程序.cpp             # 编译器入口（命令行解析、REPL）
```

## 核心模块说明

### 前端

**词法分析器** (`词法分析器`)：将 UTF-8 源代码转换为标记流。支持中文标识符、中文关键字、字符串插值 (`f"..."`)、单行/多行注释。

**语法分析器** (`语法分析器`)：递归下降解析器，使用优先级爬升处理表达式。支持：
- 变量/常量声明、赋值、复合赋值
- 如果/否则如果/否则、循环、当循环、遍历
- 匹配语句、中断/继续
- 函数定义、匿名函数（闭包）
- 结构体、枚举、映射、元组
- 模块导入

**抽象语法树** (`抽象语法树.h`)：定义所有 AST 节点类型。表达式和语句使用继承体系，通过 `类型` 枚举区分。

### 后端（LLVM）

**符号表** (`符号表`)：管理变量作用域栈，跟踪变量类型（浮点、指针、结构体、映射、字符串数组、常量、枚举、闭包）。

**代码生成器** (`代码生成器`)：两遍编译——
1. 第一遍：声明所有函数签名（支持前向引用）
2. 第二遍：生成函数体

内置函数（`打印`、`长度`、`查找`、`子串`、`转字符串`、`绝对值`、`最小值`、`最大值`、文件 IO 等）在代码生成阶段直接内联为 C 运行时调用。

### 虚拟机

**字节码** (`字节码`)：定义 60+ 操作码的寄存式指令集。每条指令 6 字节（操作码 + A/B/C + 偏移）。支持常量池、函数表、入口函数。

**字节码编译器** (`字节码编译器`)：将 AST 编译为字节码。使用寄存器分配策略，支持短路求值。

**虚拟机** (`虚拟机`)：栈帧式寄存器虚拟机。支持整数/浮点/字符串/数组/闭包/结构体值类型。

### 运行时

**运行时辅助** (`运行时辅助.c`)：提供 UTF-8 字符位置转换、字符计数、映射查找/设置/获取等 C 函数，供 LLVM 生成的代码链接使用。

## 语法定义

语法定义文件 `语法/日月.语法` 使用自定义格式，包含词法规则和语法规则。`工具/解析器生成器` 可解析此文件并生成词法/语法分析器骨架代码。

## 构建系统

使用 GNU Make，主要目标：

| 目标 | 说明 |
|------|------|
| `make` / `make all` | 编译日月编译器 |
| `make 测试` | 运行 C++ 单元测试 |
| `make 运行` | 编译并运行默认示例 |
| `make 虚拟机` | VM 模式运行示例 |
| `make 自举` | 三级自举测试 |
| `make 清理` | 清除构建产物 |

## 依赖

- **clang++** (C++17)
- **LLVM 22**（仅 LLVM 后端需要）
- **MSYS2**（Windows 构建环境）
