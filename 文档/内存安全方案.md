# 日月 内存安全方案

> 目标：为日月补齐内存安全，消除越界/悬垂/脏读等不安全行为。
> 本文档给出**现状诊断 → 路线选择 → 分阶段调整清单 → 验证方法**，作为实施依据。
> 结论基于仓库实测源码证据。

---

## 一、内存安全的分类（要防什么）

| 类别 | 说明 |
|---|---|
| 空间安全 | 数组/切片越界读写 |
| 时间安全 | 悬垂指针、use-after-free、double free |
| 初始化安全 | 未初始化读 |
| 空指针安全 | 解引用空指针 |
| 类型安全 | 指针伪造、类型混淆 |
| 并发安全 | 数据竞争 |

## 二、现状诊断（证据）

| # | 现状 | 证据位置 |
|---|---|---|
| 1 | **无边界检查**：`arr[i]`、`x = arr[i]` 直接裸 `创建边界内GEP` | `源/后端/代码生成器_表达式.cpp` L1411-1430；`源/后端/代码生成器_语句.cpp` L270-295 |
| 2 | 仅运行时内建 `动态数组获取/设置/删除` 有 `0≤i<大小` 检查，且**静默返回 0** | `源/运行时/运行时辅助.c` L1887-1898 |
| 3 | **长度信息丢失**：动态数组在语言层是裸 `int*`；分片 `arr[1:3]` 只返回起始地址裸指针 | `源/后端/代码生成器_表达式.cpp` L1432-1442 |
| 4 | **无自动释放/无所有权**：90 处 `malloc/realloc/strdup`；`释放动态数组` 是**用户手动**内建，编译器**从不自动调用** | `源/共享/内置函数表.h` L139 |
| 5 | **GC 是「死」的**：`注册GC对象` 从未被 codegen 调用，`GC启用=0` | `源/后端/C运行时声明.h` L88；`源/运行时/运行时辅助.c` L2527-2531 |
| 6 | 局部变量**必带初值**（语法 `值 = 变量名`），局部未初始化读风险低 | `源/后端/代码生成器_语句.cpp` L183-198 |
| 7 | 自举侧镜像同样行为 | `自举/发射.心` L444；`自举/语法_树.心` L973-974 |

**结论**：当前模型 ≈ **C 风格裸指针 + 手动 malloc 且从不释放**。
- 时间安全：主要是**泄漏**（不 UB 但内存持续增长）。
- **空间安全：完全无防护（越界即 UB）**。
- GC：仅摆设。

## 三、路线对比

| 路线 | 做法 | 改动量 | 效果 | 取舍 |
|---|---|---|---|---|
| **A 运行时硬化** | 保留裸/手动模型，加边界检查 + 空检查 + 零初始化 + 启用 GC | 小 | 防越界/悬垂(GC)/脏读 | 有运行时开销 |
| **B 自动内存管理** | 真 GC 或 ARC，分配自动注册/回收 | 中 | 时间安全 + 无泄漏 | 需运行时改造 |
| **C 所有权 + 借用** | Rust 式编译期检查 | 大 | 全维度、零 GC | 需重构类型系统与前端 |

**推荐路径**：**A → B**；C 仅在「既要无 GC 又要内存安全」时才值得。

## 四、阶段 1：运行时硬化（具体调整清单）

> 原则：先做**代价低、收益高**的项，全部可通过回归验证。

### 4.1 运行时层（`源/运行时/运行时辅助.c`）
- [x] **堆对象零初始化**：`创建动态数组` / `创建动态字符串数组` / `创建通道函数` 的 `malloc` 改 `calloc`；增长路径 `realloc` 后 `memset` 清零新尾段，维持「容量内未写槽位恒为 0」（消除脏读）。
- [ ] **接上 GC**（可选）：把所有 `malloc/strdup` 出口改为 `注册GC对象(...)`；`main` 调 `启用GC()`；修复保守扫描（现仅扫 4096 个栈字、单表上限 1024，易漏/误判）。
- [x] 新增检查辅助：`运行时边界检查(索引, 长度, 位置)`、`运行时空检查(指针, 位置)`，失败即打印中文诊断并 `exit(1)`。
- [x] 内建 `动态数组获取/设置/删除/插入` 越界时**由静默返回 0 改为报错**（可开关：env `日月边界检查`，默认关；须用 `_wgetenv` 走 UTF-16，因 Windows 窄环境按 ANSI 码页编码，中文名与 UTF-8 字面量不匹配）。默认关的原因：自举编译器（`自举/解析器.心`）依赖 `动态数组获取` 越界返回 0 表达 EOF。

### 4.2 后端 IR 生成（`源/后端/代码生成器_表达式.cpp`、`_语句.cpp`；自举侧 `自举/发射.心`、`自举/语法_树.心`）
- [x] **局部定长数组**：索引/下标赋值处，编译期已知长度（`数组类型->getNumElements()`），插入 bounds check。**默认开**（用户决策）：新增运行时 `运行时数组越界陷阱(索引, 长度)`；宿主 `代码生成器::插入数组越界检查`（读 `_表达式.cpp`、写 `_语句.cpp`）、自举 `发射.心::发射越界检查`（读 `语法_树.心::发射下标访问`、写 `::发射下标写`）双链镜像——索引零扩展到 `整数64` 后 `无符号大于等于 长度` 即跳陷阱块调用中止，否则落穿继续。
- [x] **动态数组胖指针（语言层）**（用户决策：默认开）：动态数组在运行时结构已带长度（`动态数组={int* 数据; int 数组大小; int 容量}`、`动态字符串数组={const char** 数据; int 数组大小; int 容量}`），语言层 `arr[i]` / `arr[i]=值` 此前不经长度检查。现新增**恒开启**运行时入口 `动态数组索引获取/设置`、`动态字符串数组索引获取/设置`（越界即 `运行时越界报告` 并 `exit(1)`，与内建 `动态数组获取/设置` 默认返回 0 以兼容自举解析器 EOF 语义不同）；双链镜像——自举借用独立表达式类型 `动态数组`/`动态字符串数组`（局部类型码 `D`/`E` → 查类型 `10`/`11`），宿主 `符号表::设置动态数组变量/是动态数组/获取动态数组元素` 登记元素种类，`下标访问`（`_表达式.cpp`）与 `下标赋值语句`（`_语句.cpp`）命中即改走上述入口。
- [x] **字符串胖指针（选项 2 落地，默认开）**：`字串` 在语言层是**指向 `{ 数据, 长度 }` 的指针**。自举链新增 `发射字符串结构常量表`（字面量入 `私有 常量 { 指针, 整数32 }`）与运行时助手 `胖字符串包装/数据/长度/字符码/拼接/子串/取字符/转整数/比较`；在「内建/运行时 C」边界按需**包装**（结果为 `字符串` 且非「已是胖指针」的调用）与**解包**（传给非用户函数的实参），使语言层胖字符串与运行时 `const char*` 互通。宿主种子链维持裸 `char*`（语义等价——仅需支撑自举，不参与不动点文本比对）。
- [x] **语言级「指针」类型（不透明句柄，默认开）**：新增局部码 `P`（`查类型`=12、`查函数返回类型`=4、`类型转IR`/`输出码转IR`/`输出码到表达式类型`=`指针`），把自举与 peg 中**实为运行时句柄**（动态/动态字符串数组、CST 子列表、`元数据行`、`当前函数局部号表`、`令牌*` 数组）却写作 `:字符串` 的声明改标 `:指针`；`发射` 全链（存储/加载/返回/普通调用/形参复制/局部与全局声明）双链镜像支持。**根因**：包装/解包按静态类型 `字符串` 触发，而裸句柄与真字符串共用 `字符串` 类型即被误包装/误解包（二次自举 `二级.exe` 堆损坏 `STATUS_HEAP_CORRUPTION`）；类型分离后消除误判。
- [x] **通道句柄类型纠正**：`创建通道` 结果由 `字符串` 改 `指针`（通道句柄是运行时结构体指针，非字符串），消除其被误包装/解包的段错误。
- [x] **分片返回胖指针**（带长度），不再返回裸偏移：`arr[起:止] / [起:] / [:止] / [:]` 现返回运行时胖切片 `{数据, 长度}`（自举 `切片创建/切片数据/切片长度/切片取整数/切片取指针`）；切片下标读改走带长度检查的运行时入口（越界即中止）。宿主与自举双链镜像。
- [x] **解引用前空检查**（成员访问/方法调用/映射取值）：新增运行时 `运行时空检查(指针, 位置)`（空则打印「运行时空指针: <位置>」并 `exit(1)`）。**双链镜像**——宿主新增 `解析并检查解引用指针`（栈槽且分配类型为指针 → 加载出句柄后检查；本身即句柄值 → 直接检查；栈上结构体值 / 全局存储地址恒非空 → 跳过），插入 `查找结构体成员地址`（成员访问/成员赋值）、成员赋值调用点、映射取值、方法调用接收者四处；自举新增 `发射空检查`，插入 `发射成员访问` / `发射成员调用` / `发射下标访问`（映射分支）三处。**两链表示差异**：自举的结构体/映射变量是**指针句柄**（可被置空，检查可真实触发），宿主为**栈上的结构体值 / 全局存储地址**（恒非空，检查近乎不可达）——故运行时中止证据只在自举链可获得。
- [ ] **堆分配 calloc 语义清零**（若运行时未改）。

### 4.3 前端/类型系统（`源/前端/*`；`语法规范.md`）
- [ ] 引入类型标注 `切片[T]` / `[T]`（当前**无 `整数[]` 标注**，见 `语法规范.md` L837），把长度带进类型。
- [ ] 可选：`可变/不可变`、`空/非空` 类型。
- [ ] 仅路线 C 需要：生命周期/借用注解 + 借用检查器。

### 4.4 并发（若协程真并行）
- [ ] 引入原子/同步原语；否则明确「协程单线程运行」以规避数据竞争。

## 六、验证方法

1. `bash run_tests.sh` 全量回归须保持 **Pass ≥ 87 / Fail = 0**。
2. 新增越界用例（如 `示例/越界检查测试.心` + `.期望`），确认越界被拦截而非 UB。
3. `make 自举` 不动点（`中间码1.ll == 中间码2.ll`）须仍成立。
4. 宿主与自举编译器行为一致（同一源码产物一致）。
