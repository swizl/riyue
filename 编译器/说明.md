# 日月编译器

用日月语言编写的编译器组件。

## 目录

```
编译器/
├── 词法器.心      词法分析器 + 表达式求值器
├── 语法器.心      语法分析器 + 自验证
├── 种子验证.心    验证 C++ 种子编译器正确性
├── 说明.md        本文件
├── 设计.md        设计文档
├── 归档/          历史实现
└── 测试/          辅助测试 (预留)
```

## 编译流程

```
C++ 种子编译器 (源/)
    │ 编译
    ▼
词法器.心 → 词法器.exe
    │ 解释
    ▼
语法器.心 → 语法器.exe
    │ 自验证
    ▼
输出正确 → 编译器可信
```

## 运行

```bash
make 编译器
make 编译器虚拟机
```

## 组件

### 种子验证

验证 C++ 编译器能正确编译日月语言子集。
覆盖: 整数运算、比较、逻辑、控制流、函数、数组、字符串。

### 词法器

将源代码转换为标记流，支持:
- 整数字面量
- 单/双字符运算符
- 单行注释
- 优先级爬升表达式求值

### 语法器

嵌入词法器核心逻辑，对自身源码中的表达式求值。
验证编译器能正确处理自己的源代码。
