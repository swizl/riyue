# 日月编译器 — 设计文档

## 概述

日月编译器用日月语言自身编写（自编译），通过三级验证证明正确性。

## 验证链路

```
┌─────────────────────────────┐
│  种子验证                    │
│  C++ 编译器编译日月子集      │
│  26 项断言全部通过           │
└─────────────┬───────────────┘
              │ 日月.exe 编译词法器
              ▼
┌─────────────────────────────┐
│  词法器                      │
│  词法分析 + 表达式求值       │
│  54 项断言全部通过           │
└─────────────┬───────────────┘
              │ 词法器.exe 解释语法器中的表达式
              ▼
┌─────────────────────────────┐
│  语法器                      │
│  对自身源码中的表达式求值    │
│  30 项断言全部通过           │
└─────────────────────────────┘
```

## 组件设计

### 种子验证 (种子验证.心)

验证 C++ 种子编译器能正确编译日月语言子集。

测试覆盖:
- 整数运算 (加/减/乘/除/取模)
- 比较运算 (<, >, <=, >=, ==, !=)
- 逻辑运算 (&&, ||, !)
- 控制流 (如果/否则/否则如果)
- 循环 (当循环, 循环)
- 函数调用与递归
- 数组访问与赋值
- 字符串操作 (长度, 拼接)
- 中断/继续

### 词法器 (词法器.心)

词法分析器将源代码转换为标记流。

标记类型:
- 数字 (T_NUM = 1)
- 标识符 (T_IDENT = 2)
- 运算符 (T_PLUS..T_NOT = 3..23)
- 文件结束 (T_EOF = 99)

表达式求值器使用优先级爬升算法:
- 优先级 1: || (逻辑或)
- 优先级 2: && (逻辑与)
- 优先级 3: == != < > <= >= (比较)
- 优先级 4: + - (加减)
- 优先级 5: * / % (乘除取模)

### 语法器 (语法器.心)

嵌入词法器核心逻辑，对从词法器源码中提取的测试表达式求值。
验证编译器能正确处理自己的源代码。

## 已知限制

- 仅支持整数算术
- 仅支持表达式求值 (无变量赋值、控制流)
- 字符串比较用 ?= (!= 做指针比较)
- 不用 ||/&& 与 ?= 组合 (类型不匹配)
- 不用前向声明 (语言不支持)

## 设计约束

日月语言不支持模块导入，每个组件文件独立编译。
词法器和语法器共享词法分析代码，语法器中维护完整副本。
修改词法器时需同步语法器。
